# Phrolova v2.0.80-preview.8

Preview release fixing Bilibili live preview resolution and CDN routing.

### Key Changes
- **Bilibili Live Preview and CDN Failover Optimization**:
  - Bilibili live streams provide multiple HLS CDNs (`ts` and `fmp4`). Certain regional `ts` hosts (e.g. `ov-gotcha105`) frequently timeout outside mainland China.
  - Optimized CDN probing timeouts to quickly skip unreachable CDN endpoints within 1.5 seconds and instantly connect to active endpoints (`fmp4` / `ov-gotcha207`).
  - Automatically promote the verified working CDN to first priority to accelerate subsequent preview queries and recordings.
  - Added dedicated `bilibili_headers` (with exact room Referer) in `preview_proxy` to avoid 403 Forbidden errors when loading preview manifests and segments.

- **Inherited from Earlier Previews**:
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

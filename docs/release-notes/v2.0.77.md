Add PandaTV live recording and PopkonTV live, VOD and clip support, with scoped account authentication and clearer preview errors.

## Changes

- Add **PandaTV (팬더티비)** to Live with channel monitoring, Streamlink HLS recording, in-dashboard previews, available broadcast qualities and optional Netscape cookies.
- Add **PopkonTV (팝콘티비)** to Live and Videos. Support full broadcast links, `channel@partner` identifiers, `/vod/<id>` and `/clip/<id>` links. Preserve partner identity throughout registration, monitoring and playback.
- Keep the existing download queue, original/advertised qualities, final output containers, media inspection and processing history. PandaTV remains live-only. The dashboard now has **10 live platforms** and **17 video source choices**.
- Add authentication controls for both platforms. Decode explicitly imported PopkonTV account cookies locally and send account authorization only to the website API; media CDN requests exclude API bearer tokens and client headers. Browser sign-in alone does not authenticate the Phrolova server.
- Respect login, adult verification, password and paid/member access requirements. A denied HTTP 200 API response never grants playback. Missing or unavailable qualities and mismatched media identities are reported explicitly.
- Rewrite standard and Twitch low-latency HLS prefetch links through opaque preview URLs. Preserve actionable authentication and access errors in live previews.
- Update the English README, repository description and platform guides, including public repository access and cookie setup. Add platform labels across all eight languages (**887 translation keys per locale**).

# Phrolova v2.0.96

## Reconnect Hang Fix
- Fixed a bug where a failure during pipeline reconnect (such as `The page needs to be reloaded` or transient 429) left the recording pipeline permanently stuck in `reconnecting` state, preventing subsequent retries.
- Wrapped `reconnect()` in exception handling to safely roll back pipeline state to `ERROR` with proper closure and retry policies.
- Added stall detection in Conductor for closed/inactive pipelines in `reconnecting` state, automatically triggering retry recovery.
- Added `The page needs to be reloaded` to YouTube cookie fallback markers to automatically use registered cookies when web token refresh is demanded.

## Validation
- Unit tests verifying state rollback and Conductor stalled pipeline recovery passed.
- 77 YouTube backend regression tests passed.
- Release metadata tests passed.

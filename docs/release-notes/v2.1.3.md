# Phrolova v2.1.3

## Official Windows x64 Release

### What's Changed
- **Twitch TTV-AB v23.0.2 Engine & Settings Integration**:
  - Added dedicated ON/OFF toggle switch for Twitch TTV-AB ad blocking in Settings > Download > Twitch (`twitch_ttv_ab_enabled`).
  - Integrated TTV-AB clean playerType routing (`playerType=popout` / `embed`) to bypass pre-roll and mid-roll SSAI ad injection.
  - Complete ad metadata detection matching: `twitch-stitched-ad`, `twitch-ad`, `X-TV-TWITCH-AD`, `/adsquared/`, `SCTE35-OUT`, `EXT-X-CUE-OUT`, `MIDROLL`.
  - Background automated ad event spoofing (`ClientSideAdEventHandling_RecordAdEvent`) to prevent Twitch 480p forced downgrades.
  - HLS preview proxy ad tag filtering for uninterrupted web dashboard playback.
- **Ani365 (애니365) Enhancements**:
  - Full support for root and www domains (`ohli365.org`, `www.ohli365.org`).
  - Standard BCP 47 language code mappings for MegaPlay multi-language subtitles (`zh-Hans`, `zh-Hant`, `id`, `ms`, `th`, `vi`, etc.).
- **TVWiki (티비위키) Enhancements**:
  - Expanded support for 13 new dynamic media CDN distribution domains (`polaredge239.com`, `cosmiccore763.com`, `vividport408.com`, etc.) and regex domain matching.
  - Verification across all 12 platform categories (`movie`, `kor_movie`, `drama`, `ent`, `sisa`, `world`, `ott_ent`, `short_drama`, `ani_movie`, `animation`, `old_ent`, `old_drama`).
  - Clear user-friendly guidance for unreleased/metadata-only titles.
- **UI & System Logging Fixes**:
  - Improved layout and padding for log breakdown panels and clean time formatting.
  - Smooth active log retention after clearing logs without deselection.
- **Clean Broadcast Termination for Restricted Streams**:
  - Fixed an issue where channels switching to private or restricted post-broadcast triggered infinite monitoring error loops (`감시 실패 · 누적=...`).
  - Now cleanly treats post-broadcast authorization errors (403 Forbidden / unavailable) as normal broadcast termination, smoothly completing any active recording.

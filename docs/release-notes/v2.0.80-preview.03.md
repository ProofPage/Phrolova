# Phrolova v2.0.80-preview.3

Preview release resolving remux validation failures ("변환 후 프레임레이트가 달라졌습니다") caused by live stream timestamp discontinuities.

### Key Changes
- **Live Stream Timestamp Discontinuity Tolerance in Remux Inspection**:
  - Live streams (such as RPLAY HLS) frequently experience network jitter and timestamp discontinuities (`timestamp discontinuity`, `Non-monotonic DTS`), which distort the calculated `avg_frame_rate` (frame count / duration) on the source TS container.
  - Stream copy (`-c copy`) remuxing now validates both `avg_frame_rate` and nominal `r_frame_rate`, and acknowledges normal timestamp offset normalization when discontinuity warnings are present in FFmpeg output.
  - Fixes false-positive "변환 후 프레임레이트가 달라졌습니다" errors when remuxing valid live recordings.

- **Inherited from Earlier Previews**:
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.
  - Dashboard live preview optimization for low-latency & time-shifted CHZZK streams.
  - Startup grace period preventing initial 502 errors on guest CHZZK previews.

## Phrolova 2.0.53

CHZZK 다운로드 파일 검사 오류 처리를 개선하고 실시간 녹화 관리 화면을 정리했습니다.

- FFprobe를 FFmpeg와 독립적으로 탐색하며 Linux·Termux 경로, 실행 권한, 한글·공백 파일명을 처리합니다.
- 파일 검사에서 파일 없음·빈 파일·실행 실패·시간 초과·잘못된 응답을 구분하고 상세 진단을 보존합니다.
- 다운로드 완료와 파일 검사 상태를 분리합니다. 검사 실패로 다운로드가 실패 처리되거나 파일이 삭제되지 않습니다. **다시 검사**를 지원합니다.
- CHZZK URL 등록, 중복 안내, 대기 목록, 다운로드 완료 카드와 통계의 한국어 문구를 통일했습니다.
- 실시간 녹화 그리드·목록 보기가 같은 카드·상태·API를 사용합니다. 목록 보기는 채널·통계·제어·관리 기능을 가로로 정렬합니다.
- 녹화 시간·파일 크기·저장 속도·비트레이트 레이블과 단위를 표시하고 마지막 측정값을 유지합니다.
- 자동 녹화와 녹화 제어 요청 중 중복 조작을 방지하며 태그 관리·상세 보기·순서 변경과 모바일 접근성을 유지합니다.

### 업데이트

녹화·다운로드를 마친 뒤 기존 프로그램을 종료하고 업데이트하세요. 설정·DB·다운로드 파일을 보존하세요.
Windows는 첨부된 실행 파일을 사용하세요. Linux·Termux는 소스와 기존 설치 안내를 사용하세요.

### 검증

관련 백엔드 회귀 테스트, 실제 MP4·TS 검사, 3GB TS 검사와 Chromium 기반 다운로드 UI 검증을 수행했습니다.
실제 Android Termux·ARM64 장치 및 외부 CHZZK 방송 다운로드는 이번 로컬 검증에서 실행하지 않았습니다.
Windows 실행 파일은 GitHub Actions에서 빌드하고 Windows Defender 검사를 통과한 경우 게시합니다.

# Version 2.0.53

Improve CHZZK download inspection and live recording management.

## Media inspection

- Resolve FFprobe independently of FFmpeg, including Linux/Termux paths, executable permissions and filenames containing spaces or Korean text.
- Distinguish missing/empty files, execution errors, timeouts and invalid responses, retaining diagnostic details.
- Keep download completion separate from inspection results. Failed inspection does not delete the file or mark the download as failed; inspection can be retried.

## Interface

- Align CHZZK URL registration, duplicate notices, queues, completed cards and Statistics terminology.
- Share channel cards, state and APIs between live grid/list views; align channel details, metrics and controls in list view.
- Label recording duration, file size, write speed and bitrate with units and retain the last measured values.
- Prevent duplicate recording actions while requests are pending, preserving tags, details, reordering and mobile accessibility.

## Validation

Backend regressions, real MP4/TS inspection, a 3 GB TS file and Chromium download controls were checked. This local validation did not include Android Termux/ARM64 devices or external CHZZK downloads. Windows publication uses the Actions build and Defender scan.

## Upgrade

Finish active work and stop the app before updating. Preserve configuration, the database and media. Use the attached executable on Windows; Linux/Termux use source and their installation guides.

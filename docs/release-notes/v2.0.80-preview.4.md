# Phrolova v2.0.80-preview.4

Preview release providing instantaneous live preview resolution for guest/cookie-less CHZZK broadcasts.

### Key Changes
- **Instant CHZZK Preview Resolution via Official Time-Machine Endpoint**:
  - For adult or restricted CHZZK broadcasts without login cookies, standard `livePlaybackJson.media` is omitted.
  - `ChzzkLiveEngine.get_preview_url` now immediately resolves the official HLS stream URL via the time-machine endpoint using the broadcast's `liveId`.
  - Preview requests no longer wait for the background recording pipeline to finish its 5-second initial handshake, completely eliminating transient 502 errors and rendering the live stream on the dashboard immediately.

- **Inherited from Earlier Previews**:
  - Live stream timestamp discontinuity tolerance during remux inspection (fixes "변환 후 프레임레이트가 달라졌습니다").
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.
  - Dashboard live preview optimization for low-latency & time-shifted CHZZK streams.

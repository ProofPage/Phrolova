# Version 2.0.51

## CHZZK VOD preparation and batch downloads

- Add drag-and-drop and multi-URL registration to the existing Downloads page.
- Show metadata cards, real per-video quality options and individual/batch start controls.
- Persist prepared VODs and selected quality using the existing SQLite history.
- Keep pause/resume/cancel/retry controls and add history-only removal; downloaded files are preserved.
- Add Korean, English and Japanese UI strings and responsive mobile controls.
- Keep CHZZK live recording on Streamlink -> FFmpeg. Existing yt-dlp, manual CDN selection and FFprobe checks remain in use.

Validation: 490 Python tests passed; TypeScript and production build passed. Chromium UI checks passed at 390/1440px; existing 320/390/820/1024/1440px player/layout regressions passed. Local mock CDN downloads, merging, cancellation, shutdown and restart persistence tested.
External CHZZK/CDN downloads and this patch on Termux, ARM64 and Windows devices remain unverified. Windows executable is CI-built.
Existing chzzkpy dependency advisory limitations remain. See https://github.com/ProofPage/Phrolova/blob/v2.0.51/docs/vod-batch-ui-audit-ko.md.

Windows: stop the application before replacing the executable; preserve settings and data.
Linux/Termux: use source archives and https://github.com/ProofPage/Phrolova/blob/v2.0.51/docs/linux-guide.md or https://github.com/ProofPage/Phrolova/blob/v2.0.51/docs/termux-guide.md. The exe is Windows-only.

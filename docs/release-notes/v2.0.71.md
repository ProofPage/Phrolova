Fix Twitch live previews that failed to load even when the channel was live and its stream URL resolved successfully.

## Twitch preview fix

- Allow Twitch playlists, redirects and media segments to use different HTTPS hosts under `ttvnw.net`. The previous preview allowlist rejected the segment CDN, preventing playback.
- Scope the additional CDN permission to Twitch previews and continue rejecting private addresses, credential-bearing URLs, insecure URLs and lookalike domains.
- Rewrite Twitch prefetch URLs into opaque same-origin preview URLs. Omit unused Twitch trigger metadata so signed upstream addresses stay on the server.
- Preserve domain-scoped cookies and keep Twitch authentication credentials off media CDN requests.

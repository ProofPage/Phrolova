# Version 2.0.13

This release updates Rookery to the renamed repository, ProofPage/Phrolova, and fixes the stale update information shown in System Management.

- Fixed the update checker reporting v2.0.9 as the latest release because it queried the original Rookery repository. It now checks ProofPage/Phrolova and follows GitHub redirects.
- Updated the repository link in System Information and the Linux install and update scripts.
- Retained the v2.0.11 Chzzk VOD reliability fixes, including Akamai-first CDN fallback, more resilient retries, and incomplete-download detection.
- Kept UPX disabled for Windows builds and run a Windows Defender scan before publishing the release.

**Upgrade note:** Versions built before this repository rename may not follow GitHub's API redirect. If your app does not find this release, download the v2.0.13 Windows x64 executable below and replace the existing `Rookery.exe` once. Your settings and recordings database stay in place when you replace the executable in the same folder.

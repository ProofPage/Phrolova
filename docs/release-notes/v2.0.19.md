# Version 2.0.19

## Live recording

- Switched live HLS/DASH segment capture to Streamlink and kept FFmpeg for writing recordings.
- Preserved CHZZK Time Machine offsets, quality selection, request headers, and scoped cookies.
- Added segment and playlist retry handling for more resilient live capture.

## Interface and VOD fixes

- Centered icons and their adjacent text in shared card, page, collapsible-card, and metric headers.
- Prevented external yt-dlp configuration from injecting global Cookie headers into app-managed VOD and live extraction.
- Kept the legacy download-settings API visible alongside the new live-settings API for older clients.

Download the Windows x64 executable and replace the existing application executable. Settings and saved data are preserved.

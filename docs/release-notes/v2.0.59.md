# Version 2.0.59

## 숲·씨미 라이브 플레이어 수정
- 숲·씨미 미리보기를 실제 HLS 동영상으로 전환했습니다. 재생·일시정지·음량·전체화면을 조작할 수 있습니다.
- 몇 초마다 정지 이미지를 교체하던 방식에서 발생한 화면 끊김을 해결했습니다.
- 네트워크 상태에 따라 화질을 자동 조정하고 일시적인 연결 오류를 제한적으로 재시도합니다. 재연결 시 음량·음소거 설정을 유지합니다.
- 서버 미디어 프록시에 플랫폼 요청 헤더와 도메인별 쿠키를 적용했습니다. TLS 인증서 검증과 서명 URL 보호를 유지합니다.
- Streamlink와 yt-dlp가 함께 로드될 때 숲 URL 해석을 막던 정규식 래퍼 충돌을 수정했습니다.

## 카드 정렬
- 좁은 채널 카드의 미리보기를 상세 정보 위로 배치해 플랫폼별 상세 항목 수에 따라 영상 시작 위치가 달라지지 않도록 했습니다.
- 넓은 목록 화면은 정보와 영상을 나란히 배치합니다.

## 검증
- 전체 백엔드: 795 passed, 1 skipped, 4 subtests passed.
- TypeScript·프런트엔드 빌드 및 관련 Python Ruff 통과.
- 세 플랫폼 HLS 재생·플레이어 조작 12개 조합, 반응형 20개 조합과 오류 복구 검증 통과.
- 상세 화면 확장·축소·정리, 녹화 설정·VOD 등록·쿠키 통합 테스트 통과.
- 실제 공개 숲·씨미 방송으로 재생·일시정지·재개·음량 조작을 확인했습니다.

기존 Streamlink 녹화, yt-dlp 다운로드, 사용자 설정·녹화 이력·파일을 유지합니다.

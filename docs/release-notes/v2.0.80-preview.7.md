# Phrolova v2.0.80-preview.7

Preview release eliminating false-alarm "재연결 중" UI flickers during healthy CHZZK recordings.

### Key Changes
- **Eliminate Frequent "재연결 중" / "녹화 중" State Flapping on CHZZK**:
  - Removed premature `recovery_started` event triggers during routine segment download hedging when no segment gap exists.
  - Added a 5-second silence threshold before marking a recording as `reconnecting` during background recovery, ensuring the UI status remains stably on "녹화 중" as long as data packets continue to arrive smoothly.

- **Inherited from Earlier Previews**:
  - Remux duration inspection tolerance for TS timestamp discontinuities on live streams.
  - Streamlink live queue deadline expansion to prevent premature stream cutoffs.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

# Phrolova v2.1.5

## Official Windows x64 Release — Comprehensive Anime & VOD Hub, Dynamic Sources & Streaming Stabilization

Phrolova v2.1.5 delivers an expanded Anime & VOD Hub with real-time seasonal catalogs, weekly broadcast schedules, custom domestic/international sources, and direct integration with the Phrolova high-speed download engine.

### Key Highlights

- **Multi-Source Content Expansion**:
  - Integrated dedicated parsers and stream resolvers for **Zzapflix**, **AniWolf**, **AniWeek**, **Ohli24**, and **Moeni**.
  - Dynamic source switching directly from the Anime Hub header with instant catalog reloading.
  - Native handling of Inertia SSR metadata, CDNDania, and MichealCDN 1080p high-speed video streams.

- **Streaming & Player Enhancements**:
  - Responsive 16:9 aspect ratio stabilization and dual-controller overlay conflict resolution.
  - Subtitle styling drawer with dynamic scaling (50%~200%) and sync offset adjustments.
  - AniSkip automated opening and ending chapter detection and one-click skipping.

- **Storage & System Stabilization**:
  - Direct Windows File Explorer handoff for VOD and Anime download directories without browser popups.
  - Real-time download task state binding and removal of mock task data.
  - Full Korean title localization mapping dictionary and TMDB metadata integration.
  - Cloudflare WAF compatibility enhancements for reliable catalog and schedule retrieval.

# Phrolova v2.1.5

## Official Windows x64 Release — Anime Hub, Streaming Player & AniSkip Integration

Phrolova v2.1.5 introduces an integrated Anime Hub with seasonal schedules, multi-facet catalog browsing, an advanced streaming player with subtitle styling, AniSkip intro/outro skipping, and direct handoff to the Phrolova high-speed VOD download engine.

### Key Highlights

- **Interactive Anime Hub & Weekly Schedules**:
  - Browse current seasonal releases and real-time popularity rankings with high-resolution artwork and synopsis metadata.
  - Weekly broadcast schedules categorized from Monday through Sunday with automatic current-day focus.
  - Multi-facet catalog search filtering by 12 distinct genres, formats (TV, Movie, OVA, ONA, Special), and airing statuses.

- **Advanced Streaming Player**:
  - In-dashboard HLS streaming player with responsive aspect ratio modes (Fit, Crop, Stretch).
  - Dynamic playback rate controls (0.75x to 2x) and configurable seek intervals (5s to 30s).
  - Subtitle customization engine supporting real-time size scaling (50%~200%) and sync offset adjustments (-5s to +5s).
  - Episode navigation controls for smooth previous and next episode transitions.

- **AniSkip Automated Chapter Skipping**:
  - Automatically detects opening and ending song timestamps.
  - Provides a floating one-click skip pill and optional automated skip preference.

- **Seamless Phrolova VOD Integration**:
  - One-click episode transfer directly into the Phrolova high-speed VOD queue for fast archiving and media verification.
  - Local watch history tracking with resume playback progress and a personal library bookmarking system.

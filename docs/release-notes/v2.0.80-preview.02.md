# Phrolova v2.0.80-preview.2

Preview release addressing live preview startup transitions and eliminating initial 502 errors when monitoring CHZZK streams without cookies.

### Key Changes
- **Eliminate Startup 502 Errors for CHZZK Previews**:
  - For restricted or adult CHZZK broadcasts without login cookies, the server now waits up to 2 seconds for a newly starting recording pipeline to establish its granted media source before responding to preview requests.
  - Eliminates transient 502 errors during recording startup and allows immediate 200 playback on dashboard load without waiting for frontend retries.

- **Inherited from v2.0.80-preview.1**:
  - Automatic RPLAY session renewal via IndexedDB `refreshToken` before expiration and on 401 challenges.
  - Time-shifted live HLS preview trimming and sub-second part/preload tag stripping to eliminate preview buffering.

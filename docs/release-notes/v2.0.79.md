Fix CHZZK previews while recording and RPLAY login-file uploads. Add an explicit RPLAY login-information export tool with instructions in all eight interface languages.

## Changes

- **CHZZK live previews:** Some live-detail responses omit ordinary playback URLs even while an advertised time-machine HLS source is successfully recording. Prefer ordinary playback when available; otherwise reuse the trusted source of the same active recording, following its current recovery CDN. Do not change, restart or interrupt the recording. Stopped, unstarted, unrelated and untrusted recording sources are excluded. Existing offline and API errors remain errors.
- Send the CHZZK `Origin` and `Referer` headers through the opaque preview proxy. Signed source URLs stay on the server; account cookies and authorization headers are not forwarded to CHZZK media CDNs.
- **RPLAY authentication:** Send the selected login file as multipart/form-data. The previous JSON request default could reject a valid file with a generic input-validation message.
- Add **Copy export code** and expandable instructions under **Settings → Authentication → RPLAY**. Run the code explicitly in the console on your signed-in RPLAY page to download `rplay_session.json`, then select that file in Phrolova. No manual JSON editing is needed. Provide selectable code when clipboard access is unavailable.
- The export tool reads only RPLAY's known IndexedDB account-session record and writes the required access token, account ID and login type to a local file. It makes no network requests, exports no refresh tokens or profile data, and rejects other websites or signed-out sessions. Ordinary cookie exports do not contain RPLAY's account session. The application does not sign in automatically or share browser credentials with the server.
- Prevent a delayed initial authentication-status response from overwriting a newer upload/removal result. Update the English README, RPLAY guide and **908 translation keys across eight languages**. Keep all 11 live platforms and 18 video source choices.

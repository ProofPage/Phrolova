# Phrolova v2.1.7

## Recording and data integrity fixes

- Preserve an earlier in-flight CHZZK media segment when a later prefetched segment detects broadcast end. Reproduced with delayed media instead of suppressing the Windows CI failure.
- Close failed database initialization connections and retry migrations on the next connection attempt.
- Replace fabricated anime source catalogs and incorrect identifiers with live AniList metadata. Catalog presence does not verify availability on a playback source.
- Do not silently substitute another playback provider, invent a source-specific work ID, or select an unrelated first search result.
- Resolve non-Re:Anime playback only from an explicit, validated episode URL belonging to the selected source.
- Verify actual Zzapflix pages, episode links and advertised players instead of returning constructed URLs as successful playback.
- Correct the status of upcoming anime and update browser regression fixtures to include the download capabilities API.

## Known limitations

- AniList metadata is not a verified catalog of each playback provider. The anime player cannot infer domestic source episode URLs from MAL or AniList IDs; use a real episode URL through the supported video download flow.
- External availability, authentication and CDN restrictions still apply. No access restriction bypass is included.
- NooNoo's tested video CDN reported “Domain suspended or not configured”. HooHooTV and NooNoo integration is not included.
- This release does not restore upstream media that was already missing or certify long-duration live recording.

## Validation

- Local full backend regression: **2,098 passed, 2 skipped**, including four subtests.
- Syntax parsing passed for all **124** application Python files.
- Frontend type checking, production build and eight-language resource/behavior checks passed.
- Isolated browser checks passed: live status/menu layout at ten widths, delayed-response versus SSE ordering, VOD preparation at 390/1440 pixels, and actual subtitle cues/show-hide/invalid-file/episode cleanup.
- The browser checks use mocked APIs and do not certify third-party broadcast availability.

# Phrolova v2.0.90

## Twitch quality proxy
- Add an optional ReYohoho-compatible proxy for Twitch live quality lookup, recording and preview.
- Enable it under **Settings → Downloads → Twitch**. It is **disabled by default** and applies to the next lookup, recording or preview. Existing recordings and VOD/clip downloads are unchanged.
- Use only the four proxy servers listed by the original userscript. Fall back to direct Twitch access when proxy requests fail.

## Important account-token notice
- When enabled, the proxies receive the channel, IP address and registered Twitch login token as `auth=` in the URL. Proxy operators can retain the token. Enable only if you trust them.
- Without registered cookies, proxy requests are anonymous.
- Block proxy redirects, reject untrusted media addresses and token-echoing playlists, and mask token values in application logs. These measures do not prevent the intended proxy operator from receiving the token.
- No third-party userscript or remotely downloaded code is executed.

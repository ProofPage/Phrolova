# Phrolova v2.0.97

## 4K Live Recording & RPLAY Segment Connection Fix

### YouTube & CIME 4K Support
- Supported 4K (3840×2160) live recording for YouTube via signed live DASH streams in both real-time and time-machine modes.
- Direct remux from native fMP4 to MKV/MP4 for CIME 4K recordings without redundant TS intermediate copies, drastically saving disk space.
- Forwarded actual recorded stream resolution (`3840×2160 · 60fps`) to frontend recording metrics.

### RPLAY Segment Connection Fix
- Fixed an issue where RPLAY livestream recordings frequently disconnected with `알플레이 영상 조각 수신이 실패했습니다. 새 재생 주소로 재연결합니다.` due to missing viewer auth tokens on relative segment URLs.
- Segment requests now preserve stream auth query parameters (`creatorId`, `token`, `userId`).
- In-flight segment requests now automatically renew expired playback tokens on 403 Forbidden without breaking the recording stream.

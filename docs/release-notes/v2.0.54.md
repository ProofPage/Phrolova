## Phrolova 2.0.54

라이브 녹화 종료 후 파일 변환·검사를 자동화하고, SOOP·CIME 통합 및 라이브·다운로드 화면 개선을 반영했습니다.

- **녹화와 변환 분리:** Streamlink가 방송 중 TS를 직접 저장합니다. 녹화가 완전히 종료된 뒤 FFmpeg로 MKV/MP4 컨테이너를 변환하고 FFprobe로 검사합니다. 기본적으로 영상·음성을 재인코딩하지 않습니다.
- **저장 설정:** 전역·채널별 MKV/MP4, 원본 TS 보관 및 동시 변환 수를 설정할 수 있습니다. 녹화 시작 시 확정한 설정은 진행 중 변경되지 않습니다.
- **안전한 복구:** 변환·검사 실패 시 원본을 보존하고 다시 변환·검사 및 MKV 대체 변환을 지원합니다. 작업은 DB에 저장되며 서버 재시작 후 복구됩니다.
- **플랫폼:** 치지직·유튜브 기능을 유지하고 SOOP·CIME의 감지·인증·화질·미리보기·다운로드를 통합했습니다. 치지직 채널 ID와 링크를 모두 입력할 수 있습니다.
- **화면 개선:** 다운로드 입력을 통합하고 중복 통계를 제거했습니다. 라이브·다운로드의 카드, 플랫폼 배지, 진행률, 버튼 정렬과 그리드·목록·모바일 레이아웃을 정리했습니다. Full HD 미리보기를 지원합니다.
- **화면 정리:** 빈 미디어 허브 메뉴와 녹화 카드의 처리 상세·원본 및 완료 파일 경로 설명을 제거했습니다. 작업 상태와 파일 제어 버튼은 유지합니다.
- **기능 제거:** 채팅 수집·저장·조회 및 X Spaces 실행 기능을 제거했습니다. 기존 사용자 파일과 과거 이력은 자동 삭제하지 않습니다.

### 업데이트

진행 중인 녹화·다운로드를 마친 뒤 프로그램을 종료하고 업데이트하세요. 기존 설정·DB·녹화 파일을 보존하세요. Windows는 첨부된 실행 파일을, Linux·Termux는 소스와 기존 설치 안내를 사용하세요.

기본 저장 설정은 MP4·원본 TS 보관입니다. 기존 출력 형식 설정은 마이그레이션 시 유지합니다. TS HLS 녹화를 지원하며 DASH 전용·fMP4/CMAF 스트림은 지원하지 않는 형식으로 안내합니다.

### 검증

백엔드 회귀 테스트, 실제 Streamlink 로컬 HLS 수신, FFmpeg MP4/MKV 변환, FFprobe 검사와 3.59GB TS 변환을 검증했습니다. Chromium에서 카드 작업·설정·반응형 화면을 검증하고 TypeScript 검사·프론트엔드 빌드를 수행했습니다.

실제 업스트림 장시간 방송·제한 콘텐츠 및 Linux·Android Termux 장치 실행은 미실행입니다. Windows 실행 파일은 GitHub Actions 빌드와 Windows Defender 검사 통과 후 게시합니다.

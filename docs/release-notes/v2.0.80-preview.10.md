# Phrolova v2.0.80-preview.10

Preview release resolving SQLite `recording_jobs.source_path` unique constraint failures upon recording restart.

### Key Changes
- **Fix `UNIQUE constraint failed: recording_jobs.source_path` on Recording Start**:
  - When restarting the server or recording a broadcast that shares the same source path as a previous failed or completed session, `register_capture` previously raised an `IntegrityError` due to SQLite's unique constraint on `recording_jobs.source_path`.
  - Atomically claims and updates existing records with the new active recording session instead of crashing during `_capture_started`.
  - Fixes cascading pipeline closures and subsequent `ValueError: read of closed file` errors on TikTok, RPLAY, and other channels.

- **Inherited from Earlier Previews**:
  - Real-time video player for TikTok live previews via `mpegts.js`.
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

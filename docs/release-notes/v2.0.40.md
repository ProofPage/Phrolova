# Version 2.0.40

## Dashboard UI Improvements

- Replaced the fixed sidebar with horizontal navigation and refined spacing across the dashboard, cards, and input areas.
- Changed the default accent color for new installations to blue. Existing saved theme selections are preserved.
- Added translucent glass effects to navigation, the platform selector, notifications, and quick navigation.
- Made detailed live filters collapsible and kept the replay URL field on one line at narrow widths.
- The platform selector can now be dismissed by clicking outside it or pressing Esc.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

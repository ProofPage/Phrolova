# Phrolova v2.0.88

This release refines the existing log workspace, separates authentication selection from detail forms, and fixes quick-navigation accessibility and interaction.

## Logs

- Preserve the familiar narrow file panel and wide log viewer: a 240px sidebar, a flexible main panel and a consistent 16px gap.
- Remove the system logging specification block.
- Align timestamps, severity, service and message columns. Keep exception continuation lines readable and retain raw-line search/highlighting and original-file export.
- Improve log spacing and responsive column layout without changing recording, authentication or credential handling.

## Deno and provider installation locations

- Install Deno in its official per-user location, `%USERPROFILE%\.deno\bin\deno.exe` on Windows, respecting `DENO_INSTALL` when set.
- Reuse an existing Deno 2+ executable after checking that it runs. Never overwrite an existing user-managed runtime.
- Keep bgutil and its plugin in `%LOCALAPPDATA%\Phrolova\youtube-tools` on Windows, outside the application/download directory.
- Preserve previous application-local installations and user data. A fresh provider setup in the new location may require internet access once.

## Authentication
- Keep platform selectors at equal heights and show only the selected platform's form in a separate full-width detail panel.
- Add persistent RPLAY field labels and 44px form controls.
- Clear passwords when closing, switching authentication methods or choosing another platform; preserve existing account, cookie and session import flows.

## Quick navigation

- Add an accessible dialog title and description.
- Correct dialog geometry and backdrop click handling; preserve Escape dismissal, keyboard search/navigation and focus restoration.

## Validation and download

- Isolated-data browser checks exercise populated live views, logs, authentication, keyboard navigation, errors and responsive layouts. These do not establish real-account sign-in or live-platform availability.
- Existing JavaScript bundle-size and upstream dependency deprecation warnings remain.
- Download `Phrolova-v2.0.88-windows-x64.exe` and verify it with `SHA256SUMS.txt`. The Windows publication workflow builds the executable and scans it with Defender.

# Version 2.0.65

## UI 정리
- 라이브·동영상·통계·설정을 로그 화면과 같은 카드 경계·간격으로 통일했습니다.
- 상태 요약, URL 입력과 필터를 구분하고 동영상 화질 선택을 공용 버튼 디자인에 맞췄습니다. 선택한 화질은 옅은 강조색과 테두리로 표시합니다.
- 녹화 파일 처리 이력을 한 카드 안에 묶고 상태·오류·파일 조작을 읽기 쉽게 배치했습니다.
- 정보 탭은 한 카드로 통합했습니다. 반복 제목을 제거하고 업데이트는 맨 아래로, 저작권·FFmpeg 라이선스 안내는 라이선스 행 오른쪽으로 옮겼습니다.
- 쿠키 안내는 인증 목록 아래 공통 안내 카드에 표시합니다. 외관 탭의 중복 제목과 저장 버튼 위 불필요한 선을 제거했습니다.
- 로그 목록의 빈 공간과 좌우 카드 높이, 작은 화면·긴 번역의 버튼 배치를 보완했습니다.

## Linux·macOS·Termux 호환성
- OS별 런타임·패키지 탐색, 설치본별 PID/잠금과 정상 종료, 파일 위치 열기를 보완했습니다.
- macOS의 BSD 도구와 Homebrew 경로를 처리하고 Native Termux의 의존성·Uvicorn 프로필을 정리했습니다.
- README와 플랫폼별 설치 가이드를 최신 코드와 비공개 저장소 접근 방식에 맞췄습니다.
- Linux x64/ARM64, Windows, macOS Apple Silicon/Intel 및 ARM64 Python 3.14 Termux 의존성 프로필을 CI에서 검사합니다. 실제 Android 단말 검증은 포함하지 않습니다.

## 검증
- Windows 백엔드 전체: 925 passed, 2 skipped, 4 subtests passed. 별도 활성화한 3GiB 초과 실제 TS 검사도 통과했습니다.
- 브라우저 회귀 검사 11개를 통과했습니다. 8개 언어, 설정 저장·복원, 로그 검색·내보내기, 녹화 상태·후처리, 화질 선택·다운로드와 작은 화면 배치를 확인했습니다.
- 언어별 839개 번역 키·변수·포맷, TypeScript와 제품 빌드를 검사했습니다.

# Phrolova v2.0.95

## Post-broadcast private/unavailable live handling
- Fixed an issue where YouTube live streams that became private or unavailable immediately after broadcast ended caused infinite automatic recording retry loops and error logging.
- When a stream transitions to private or unavailable, it is now cleanly recognized as an offline state (`is_live: false`) instead of a transient monitoring failure.
- Classified "video unavailable" and "private video" as non-retryable recording errors.

## Validation
- Unit and integration tests passed for unavailable/private stream detection.
- 77 YouTube backend regression tests passed.
- Release metadata tests passed.

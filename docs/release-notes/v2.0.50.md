# Version 2.0.50

## CHZZK VOD CDN selection and download reliability

- Add persistent manual Default / Akamai CDN selection for new CHZZK VOD jobs.
- Route supported manifest, video/audio segment and HLS key requests per job; no automatic CDN fallback.
- Keep live recording on Streamlink -> FFmpeg unchanged.
- Fix separate DASH tracks, merged output paths, filename collisions and VOD settings persistence.
- Preserve completed files and show non-destructive FFprobe duration/track warnings.

Validation: 457 Python tests passed; TypeScript and production build passed. Local mock CDN HLS/DASH/AES downloads and real Streamlink HLS transport, cancellation, shutdown and restart persistence tested.
Actual external Akamai availability/path compatibility and this patch on Termux/ARM64/Windows devices remain unverified. Windows executable is CI-built.
Known limitation: existing chzzkpy dependency pins have reported advisories. See https://github.com/ProofPage/Phrolova/blob/v2.0.50/docs/cdn-audit-ko.md and https://github.com/ProofPage/Phrolova/blob/v2.0.50/docs/bug-audit-ko.md.

Windows: stop the application before replacing the executable; preserve settings and data.
Linux/Termux: use source archives and https://github.com/ProofPage/Phrolova/blob/v2.0.50/docs/linux-guide.md or https://github.com/ProofPage/Phrolova/blob/v2.0.50/docs/termux-guide.md. The exe is Windows-only.

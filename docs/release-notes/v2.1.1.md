# Phrolova v2.1.1

## Ongoing Live Continuous Recording Fix
- Fixed an issue where livestreams still in progress prematurely stopped recording when an HLS connection ended (e.g. on CDN token expiration or queue deadline).
- Instead of falsely assuming the broadcast has ended, Conductor now verifies whether the channel is still live and automatically continues recording in a fresh session.
- Automatically reset `broadcast_ended` whenever an active live status is confirmed, ensuring automatic recording never stalls while a broadcast is ongoing.

# Version 2.0.60

## 라이브 녹화 종료·복구 안정성
- 녹화 중지 시 진행 중인 세그먼트와 잔여 수신 버퍼를 저장한 뒤 파일을 확정합니다.
- 취소·강제 종료·미완성 데이터는 정상 완료로 표시하지 않고 원본을 보관합니다.
- 치지직 재연결과 파일 전환에 마지막 checkpoint와 제한된 디스크 버퍼를 인계해 누락 구간을 복구합니다.
- 변환 결과가 재생 가능해도 손상 패킷 경고가 있으면 별도의 데이터 확인 필요 상태로 표시합니다.

## 다시보기 다운로드
- HLS/DASH 조각의 TS/fMP4 구조를 검사해 잘린 조각을 성공 파일로 병합하지 않습니다.
- 403·404 등 HTTP 원인을 보존하고 대량 실패 시 요청·예약 큐를 제한합니다.
- 세로 영상 화질 선택, 앱 재시작 뒤 이어받기 파일명·part 경로 복원, 긴 한글·Windows 경로 처리를 개선했습니다.

## 화면·설정
- 라이브 카드의 공통 영역과 펼친 미리보기 배치를 정리하고 오프라인 표시도 16:9 영역을 유지합니다.
- 채널 감시 복구와 상태 갱신을 개선했습니다.
- 치지직 라이브·다운로드 CDN 기본값을 Akamai CDN으로 설정하고 Naver CDN / Akamai CDN 표시 이름을 통일했습니다. 기존 사용자가 저장한 선택은 유지합니다.
- 새 녹화 파일명에서 불필요하게 긴 작업 ID를 제거했습니다. 기존 파일은 바꾸거나 삭제하지 않습니다.

## 검증
- 전체 backend: 866 passed, 1 skipped, 4 subtests passed.
- 코드 CI: Windows x64·Ubuntu x64/ARM64 backend와 frontend 타입/빌드 모두 통과.
- Chromium 후처리·다운로드 버튼/API 및 반응형 검증 통과.
- 공개 치지직 방송 실제 수신 2건의 TS 정규화·MKV 변환·FFprobe 검사 통과.

Streamlink 라이브, yt-dlp 다운로드, 기존 설정·데이터베이스·녹화 원본을 유지합니다. FFmpeg·FFprobe는 외부 도구이며 기존 설치·경로 설정을 사용할 수 있습니다.

참고 이슈 148건 중 실제 기기·계정·저장매체가 필요한 17건은 추가 검증 대상으로 구분했습니다. Native Termux/proot 장시간 실기는 통과로 표기하지 않았습니다.

# Phrolova v2.1.8

- 치지직 라이브 CDN 지원 확대: `ex-nlive-streaming.navercdn.com`의 Akamai 후보 경로를 추가했습니다. 라이브 200개의 재생 응답을 분석하고 지원 경로의 재생목록·미디어 응답을 확인했습니다.
- VPN 재생에서 관찰된 `livecloud.akamaized.net`의 경로 기반 인증 토큰을 유지하면서 LL-HLS 폴링 매개변수를 정리합니다. 만료된 인증이나 HTTP 403을 우회하지 않습니다.
- 기본 실행·빌드 기준은 **표준 GIL Python 3.14.8 이상**입니다. 이전 Python 환경은 지원하지 않으며, 설치 도구는 호환되지 않는 가상환경을 보존해 백업합니다.
- Python 3.15 검사는 실험적 CI 대상으로 추가했습니다. 의존성까지 포함한 완전한 지원을 보장하는 항목은 아닙니다.
- 서버 검증 오류·비JSON 응답·연결 실패·타임아웃·취소 처리를 개선하고 화면에 표시되는 인증 정보를 마스킹합니다.
- Windows 가상환경 백업은 날짜 형식에 영향을 받지 않으며 백업 실패 시 원본을 삭제하지 않고 중단합니다.
- Twitch TTV-AB 광고 차단의 신규 기본값은 **OFF**입니다. 기존 저장 설정은 유지됩니다.

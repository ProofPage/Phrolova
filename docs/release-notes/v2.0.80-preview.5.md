# Phrolova v2.0.80-preview.5

Preview release fixing missing import in guest CHZZK time-machine preview resolver and adding detailed preview failure diagnostics.

### Key Changes
- **Fix Missing Import in Guest CHZZK Time-Machine Resolver**:
  - Fixed a `NameError` on `USER_AGENT` in `ChzzkLiveEngine.get_preview_url` when resolving time-machine playback without cookies.
  - Restricted and adult CHZZK live broadcasts without login cookies now successfully query the time-machine endpoint immediately, eliminating transient 502 errors on initial dashboard load.
  - Added warning diagnostics log for preview resolver failures in `api/stream.py`.

- **Inherited from Earlier Previews**:
  - Live stream timestamp discontinuity tolerance during remux inspection (fixes "변환 후 프레임레이트가 달라졌습니다").
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.
  - Dashboard live preview optimization for low-latency & time-shifted CHZZK streams.

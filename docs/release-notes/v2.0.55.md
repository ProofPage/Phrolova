## Phrolova 2.0.55

치지직 원본 스트림 처리와 녹화 복구 오류를 수정하고, 라이브·다운로드 카드 및 설정 화면을 정리했습니다.

### 녹화 안정성
- Streamlink 녹화 엔진을 유지합니다. TS 호환 스트림을 우선 사용하고, TS가 없는 방송은 원본 fMP4로 저장합니다. 녹화가 완전히 종료된 후에만 FFmpeg로 TS 정규화 및 MKV/MP4 변환을 수행하고 FFprobe로 최종 검사합니다.
- 파일 경로 충돌과 동일 채널 중복 시작, 무의미한 반복 재시도, 0 B 파일의 변환 이력 생성을 방지합니다.
- 실제 데이터 수신 전에는 녹화 시간이 진행되지 않습니다. 변환·검사 실패 시 원본을 보존합니다.
- 유튜브 JavaScript 런타임 탐색, 쿠키 전달 및 인증 오류 안내를 개선했습니다.

### 설정·화면
- 신규 기본값: 완료 형식 MKV, 치지직 강제 타임머신, 동시 다운로드 5개. 기존에 저장된 사용자의 선택값은 유지합니다.
- 치지직 라이브 CDN 선택과 플랫폼별 쿠키 파일 등록 UI를 제공합니다.
- 저장 위치와 라이브 확인 주기를 영상 다운로드·라이브 녹화 설정으로 이동했습니다.
- 전역·채널별 출력 메뉴를 MKV - Matroska / MP4 - MPEG-4로 통일했습니다.
- 라이브 상태와 녹화 제어를 분리하고, 다운로드 진행률·통계·완료 시각·검사 안내·화질 옵션·그리드 하단 버튼 정렬을 개선했습니다.
- 사이드바 이름 앞 아이콘을 제거했습니다.

### 검증
- Windows 로컬 백엔드 테스트 685개 통과, 환경 조건에 따른 6개 테스트 제외.
- TypeScript 및 프로덕션 빌드 통과.
- Chromium에서 다운로드 그리드·목록 14개 화면 조합과 실제 API 요청에 연결된 등록·화질·시작·일시정지·재개·취소·재검사 동작을 격리된 응답으로 검증했습니다.
- 새 버전 Windows 실행 파일은 GitHub Actions 빌드와 Windows Defender 검사 후 게시됩니다. SHA256SUMS.txt로 다운로드 파일 해시를 확인할 수 있습니다.
- 외부 방송 장시간 녹화와 실제 Android Termux 장치 실행은 이번 릴리즈에서 새로 검증하지 않았습니다.

### 업데이트
Windows는 첨부 실행 파일을, Linux·Termux는 소스 코드와 기존 설치 안내를 사용하세요. 업데이트 전 진행 중인 녹화·다운로드를 마치고 프로그램을 종료하세요. 기존 설정·DB·녹화 파일은 유지합니다.

# Version 2.0.33

## Recording-Hold Status in the Dashboard

- Fixed an issue where a live stream that did not meet automatic-recording conditions remained marked OFFLINE.
- The dashboard now receives the channel name, stream title, thumbnail, and LIVE status as soon as they are detected, even when no recording starts.
- Card and list views show when recording is on hold and explain why.

## Clearer Hold Reasons

- **Exclude watch-alongs:** Indicates that watch-alongs are excluded by the current settings.
- **Only record watch-alongs:** Distinguishes regular streams from streams that do not match the selected content tag.
- If watch-along information is unavailable, the dashboard shows that it is still being checked.

Recordings already in progress and manual recording remain unchanged.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

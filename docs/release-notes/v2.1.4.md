# Phrolova v2.1.4

## New Video Platforms, Adult Authentication, and Built-in Twitch Ad-Block Engine

Phrolova v2.1.4 expands VOD downloading capabilities with newly supported video platforms (Moeni, Re:ANIME), adds account ID/PW authentication and adult-content support for Animaru and Anilife, and introduces a built-in Twitch TTV-AB ad-block engine with user configuration.

### Key Highlights

- **Moeni (모에니) Integration**:
  - Full support for `moeni.net` catalog and episode streaming.
  - Implements proprietary dynamic AES-256-CBC decryption, dynamic daily key generation, and M3U8 MPEG-TS playlist reconstruction.
  - TLS fragmentation support for bypassing network SNI connection resets.

- **Re:ANIME Integration**:
  - Full support for `reanime.to` catalog and episode streaming.
  - Extracts SvelteKit SSR inline datasets for full episode listings.
  - Integrates with official server extraction APIs (`/api/flix/`) to resolve multi-server HD HLS video streams.

- **Animaru & Anilife Account / Adult Authentication**:
  - Added username/password account sign-in handlers (`/api/auth/login`) in Settings -> Authentication.
  - Added adult-restricted content session cookie injection for private/adult catalogs.
  - Updated Animaru adapter to prioritize the new `/api/anime/{id}` REST API with graceful reader fallbacks.

- **Twitch TTV-AB Ad-Block Engine**:
  - Built-in TTV-AB v23.0.2 ad-block pipeline with popout player spoofing, background ad token spoofing, and preview segment separation.
  - Added user ON/OFF toggle switch under Settings -> Downloads with 8-language localization.

- **Site Adapter Enhancements**:
  - **Linkani**: Standardized episode numbering and titles (e.g. `N화`) and calculated HLS manifest durations.
  - **Ohli24 (애니24)**: Full Inertia.js SPA parsing (`/c/...`, `/e/...`) and multi-CDN support.
  - **Ani365 (애니365)**: Expanded domain matching for `ohli365.org` and normalized MegaPlay multi-language subtitles to BCP 47.
  - **TVWiki (티비위키)**: Registered 13 new distributed media CDN patterns across all 12 categories.

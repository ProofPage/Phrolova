# Phrolova v2.0.80-preview.1

Complete removal of SOOP platform support, direct account login for RPLAY, and backend import fix.

### Key Changes
- **RPLAY Account Login**: Support direct authentication with RPLAY email and password in Settings → Authentication → RPLAY, automatically issuing and refreshing session tokens without requiring manual DevTools session exports.
- **SOOP Platform Removal**: Fully stripped SOOP live engine, VOD downloader, proxy routing, cookie credentials, and UI components from the entire codebase.
- **Backend Import Fix**: Fixed `NameError: name 'BaseModel' is not defined` in `app/api/platforms.py` preventing startup.
- **Platform & Resource Cleanup**: Updated supported platform listings, translations across 8 languages, and documentation.

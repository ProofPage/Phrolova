# Phrolova v2.0.80-preview.1

Comprehensive update including complete SOOP platform removal, direct RPLAY credential login, YouTube SABR/DASH protocol priority and PO Token Provider settings, layout improvements, and stability enhancements.

### Key Changes
- **YouTube SABR & DASH Protocol Architecture**:
  - Added configurable protocol priority (`auto`, `sabr_fallback`, `sabr_first`) supporting YouTube's next-gen SABR protocol for 2K+/4K/HDR streams alongside HLS and DASH.
  - Added video codec preference controls (AV1, VP9, H.264) and time-machine options in Settings → Download.
  - Added PO Token Provider endpoint configuration (`--extractor-args youtubepot:provider=...`) and integration guidance with [Deno](https://deno.com) and [bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider).
- **RPLAY Direct Authentication**:
  - Support direct login with RPLAY email and password in Settings → Authentication, issuing and managing authenticated tokens automatically.
  - Improved compatibility with BytePlus ABR and AWS IVS low-latency live streams.
- **SOOP Platform Removal**:
  - Fully removed SOOP live engine, VOD downloader, proxy routing, cookie credentials, and UI components from the entire codebase.
- **System Stability & UI Polish**:
  - Added `-ignore_unknown` safety flag to FFmpeg conversion pipeline to prevent transcode drops on unknown stream types.
  - Redesigned System Logs side panel to eliminate empty gaps, adding live monitoring status, last entry timestamps, and full spec details.
  - Localized platform names for Korean locale (Kick → 킥, Bilibili → 빌리빌리) and updated platform-specific cookie guidance.
  - Full i18n synchronization and validation across all 8 supported languages.

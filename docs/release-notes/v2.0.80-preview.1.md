# Phrolova v2.0.80-preview.1

This refreshed preview fixes an RPLAY video compatibility issue and retains the existing preview features. The version remains `2.0.80-preview.1`.

## RPLAY Video Compatibility Fix
- Added `api2.rplay.live` to the exact media-host allowlist. Valid video URLs issued by RPLAY through this server are no longer rejected as unsupported.
- Kept account authorization limited to the content API; account authentication headers are not added to media requests.
- Preserved HTTPS, hostname, port, and URL validation. Lookalike domains, embedded credentials, and malformed URLs remain rejected.
- Preserved viewing-permission checks and DRM restrictions. This update does not add DRM decryption or bypass subscription, purchase, or age-verification requirements.

## Regression Coverage
- All **91 RPLAY video and live tests passed**.
- Verified 1080p and 720p downloads, output-file inspection, and download-history restoration using local test videos.
- Covered session refresh, denied viewing permissions, DRM rejection, media-host validation, and account-credential isolation.
- Corrected the session-refresh test double and updated the denied-live test to match the existing recording-permission behavior.

## Existing Preview Features
- Direct RPLAY account sign-in and session refresh.
- RPLAY BytePlus and AWS IVS playback URL handling improvements.
- Removal of SOOP platform support.
- YouTube protocol, codec, and time-machine preference controls, with setup links for [Deno](https://deno.com) and [bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider). Available playback protocols depend on the installed downloader and the recording pipeline; preference settings alone do not add SABR or DASH recording support.
- Additional log-viewer metadata, platform-specific authentication guidance, and Korean platform-name updates.
- FFmpeg remuxing commands use `-ignore_unknown`.

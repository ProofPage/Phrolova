# Phrolova v2.0.80-preview.1

Preview release introducing automatic RPLAY session token renewal and time-shifted live preview optimization.

### Key Changes
- **RPLAY Automatic Token Renewal**:
  - The browser session export tool now includes the `refreshToken` from IndexedDB (`rplay-account-session`).
  - Automatic token refresh is performed seamlessly prior to expiration (within 5 minutes) or upon receiving an authentication challenge (401), and the stored session file is atomically updated.
  - Fixes 10-minute token expiration causing monitoring and recording failures.

- **Optimized CHZZK & Live HLS Previews**:
  - Automatically trim long time-shifted HLS playlists down to the active live edge segments for dashboard previews.
  - Strip sub-second low-latency polling tags (`EXT-X-PART`, `EXT-X-PRELOAD-HINT`, `SERVER-CONTROL`) from preview streams to prevent client-proxy concurrency starvation and eliminating live preview buffering when watching without cookies.

### Verification
- Full automated test suite passing.
- Validated RPLAY session parsing, refresh API protocol, and atomic persistence.
- Verified playlist trimming and sequence adjustment without affecting recording pipelines.

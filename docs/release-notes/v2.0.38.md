# Version 2.0.38

## YouTube Channel Download Fixes

- The channel importer now reads a channel's Videos, Live, and Shorts sections and adds found items to the download queue as they are collected.
- Shows the number of items found and the collection status, including stopped, completed, and failed states.
- Skips duplicate videos and displays large channel listings 50 items at a time.
- Added YouTube cookie configuration and a JavaScript runtime for channel downloads.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

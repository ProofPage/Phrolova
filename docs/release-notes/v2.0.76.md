Add TVChak, Animaru and Ani365 video downloads, with safer handling of numbered website addresses and different playlist/subtitle formats.

## Changes

- Add **TVChak (티비착)**, **Animaru (애니마루)** and **Ani365 (애니365)** to Videos. Preserve all **16 download sources**, episode search/selection, quality controls, persistent queues, remuxing, media inspection and eight-language source labels.
- Read TVChak's actual work/episode links and player metadata. Support advertised MP4/HLS media and optional website-scoped cookies in **Settings → Authentication** or `TVCHAK_COOKIE_FILE`.
- Read Animaru's public catalog API, including special/fractional episodes and unavailable entries. Save provided VTT subtitles beside the video.
- Read Ani365's registered episode IDs from the selected work, follow its ordinary public playback flow and validate the returned MegaPlay identity. Preserve every checked quality playlist for native HLS transfer and request same-episode assets from the issuing media server. Support both language-based and hashed VTT filenames without executing player scripts.
- Recognize complete numbered hostnames for `anilife[0-9]+.tv`, `tvwiki[0-9]+.net`, `tvchak[0-9]+.com` and `animaru[0-9]+.com`. Preserve the supplied host and permit website redirects only within the same family; keep session APIs pinned and cookies scoped to their exact website. New domains are not automatically discovered.
- Fix false advertisement detection caused by randomized fragment filenames. Advertisement tags, unsupported key formats, unrelated hosts and mismatched work/episode identities remain rejected.
- Update the English README and adapter documentation with URLs, supported flows and verified behavior.

## Validation

- The complete backend regression suite is rerun from the exact release source, alongside TypeScript, production build, translation checks and **883 translation keys across eight locales**.
- Browser integration verifies all **16 sources**, episode-to-queue requests, **127 frontend/backend URL cases** and **320/390/768/1440-pixel layouts**.
- Ani365 downloaded a complete **1,370.036-second**, **359,344,925-byte** MKV through the actual VOD engine without a cookie file: **1920×1080 H.264 video**, **AAC audio** and **nine separate VTT files**. Inspection and full FFmpeg decoding passed. A second 23-episode work verified 1080p/720p/360p formats, different fragment names, hashed English subtitles and an actual MPEG-TS fragment probe.
- Animaru downloaded a complete **1,370.094-second**, **346,225,942-byte** 1080p H.264/AAC MKV and its Korean VTT subtitle without a cookie file. Inspection and full FFmpeg decoding passed.
- TVChak's declared media server supplied a **10.11-second 1080p H.264/AAC sample** that passed full decoding. On the test server, unauthenticated page requests required website verification (HTTP 202); a complete cookie-authenticated TVChak download is not claimed. Access checks are reported in the interface and are not automated.
- The Windows executable is verified against the release version, bundled platform modules, frontend assets, transparent icons, Windows Defender and SHA-256 before publication.

## Upgrade

Finish active recordings/downloads and stop Phrolova before replacing the executable. Preserve `.env`, `data`, cookie files and saved media. Source installations can update to this tag and restart; no settings migration is required.

# Version 2.0.49

## Recording stability and Linux/Termux support

- Improve headless setup, recording shutdown, cancellation, retry handling and process cleanup.
- Fix DASH patch reloading, X Spaces playlist paths, YouTube controls and history/settings persistence.
- Harden Origin checks, chat file access and secret-safe logs.
- Fix fonts, reduce overlapping UI requests and update compatible frontend dependencies.

Validation: 412 Python tests passed; TypeScript and production build passed; local Linux x86_64 download/cancel, HLS, remux and restart persistence tested. npm audit reported 0 vulnerabilities.
New changes are not device-tested on Windows, ARM64 or Termux. Windows artifact is CI-built.
Known limitation: chzzkpy pins Python dependencies with reported advisories. See https://github.com/ProofPage/Phrolova/blob/v2.0.49/docs/bug-audit-ko.md.

Windows: stop the application before replacing the executable; preserve settings and data.
Linux/Termux: use source archives and https://github.com/ProofPage/Phrolova/blob/v2.0.49/docs/linux-guide.md or https://github.com/ProofPage/Phrolova/blob/v2.0.49/docs/termux-guide.md. The exe is Windows-only.

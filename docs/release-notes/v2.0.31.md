# Version 2.0.31

## Live Recording Conditions

- Choose whether CHZZK automatic recording applies to all live streams, watch-alongs only, or all streams except watch-alongs.
- The app compares stream tags with the selected watch-along tags to decide whether to start an automatic recording. The default tag is "watch-along."
- Save default conditions for the dashboard and separate conditions for individual channels.
- Configure conditions before adding a channel, or edit them later for a registered channel.
- If tag information is unavailable, the app waits until the conditions can be checked. Changes take effect the next time automatic recording starts; recordings already in progress and manual recording remain unchanged.

## Dashboard Improvements

- Refined the page heading, icon, status indicators, and channel-add area while preserving the existing design.
- Unsaved changes are indicated, and the save button is disabled when there are no changes.
- Improved button layout on narrow screens and clarified the filter and view-switching guidance.
- Removed "simultaneous viewing" from the watch-along tag examples.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

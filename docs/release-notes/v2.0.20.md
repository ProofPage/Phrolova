# Version 2.0.20

## Storage paths

- Added separate save locations for live recordings and VOD downloads.
- Live recordings, chat logs, and X Spaces archives use the live folder; CHZZK replays, clips, and external video downloads use the VOD folder.
- Kept existing recordings and chat logs accessible when the live folder changes.

## Streamlink status

- Added Streamlink version and availability to startup console output and System Information settings.
- Included Streamlink package metadata in the Windows executable build.

Download the Windows x64 executable and replace the existing application executable. Settings and saved data are preserved.

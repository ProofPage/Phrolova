# Phrolova v2.0.80

This stable release replaces `v2.0.80-preview.1` and includes the latest recording, authentication, diagnostics and interface improvements.

## CIME UHD and Recording Reliability
- Support authorized CIME UHD playback and native 3840×2160 recording, including resolution detection from single fMP4 playlists.
- Obtain and renew UHD playback cookies through the official authorized flow. Keep cookies scoped to the intended media endpoints and preserve viewing-permission checks.
- Add per-platform playlist reload intervals and additional media query parameters with validation and media-host scoping.
- Propagate unexpected HLS worker failures, reject invalid sequence numbers and close capture processes and pipes cleanly.
- Write bounded `.losscheck` summaries of segment sequence gaps and transport errors. HTTP-FLV reports do not invent unavailable segment information.
- Improve manual retry, stopping and skip transitions. Manual retry bypasses only the application's waiting period, not service-side restrictions.
- Preserve saved broadcaster names when live metadata is empty.
- Measure FPS from sampled frame timestamps when needed without rewriting original stream metadata or re-encoding the source.

## Authentication and Compatibility
- Provide direct RPLAY email/password sign-in and session refresh.
- Improve authorized RPLAY BytePlus, AWS IVS and `api2.rplay.live` media URL compatibility.
- Preserve account-credential isolation, viewing-permission checks and DRM restrictions.
- Fix Streamlink/yt-dlp URL parsing compatibility and low-latency preview playlist handling.
- Remove SOOP platform support.

## Settings and Interface
- Add YouTube protocol, codec, time-machine and PO Token Provider preferences, with setup guidance for Deno and bgutil.
- These preferences do not by themselves add SABR or DASH recording support; available protocols still depend on the installed downloader and recording pipeline.
- Restrict new VOD output choices to MKV and MP4. Live TS recording and existing files remain supported.
- Improve logging diagnostics, platform authentication guidance, filename safety and mobile recording-card layout.
- Use FFmpeg `-ignore_unknown` when remuxing while preserving the original video.

## Validation
- Backend regression coverage: **1,881 passed, 2 skipped**, including a targeted rerun after correcting the last test's missing import.
- Browser checks passed for transport settings persistence, invalid input, VOD formats, retry/skip transitions, responsive layout and mobile tags.
- Native CIME 4K capture, MKV finalization, authorization refresh and credential-scope tests passed using local media and mocked service responses. Automated fixtures do not replace authentication with your own platform account.
- The Windows release pipeline checks translations, builds the frontend and single-file executable, scans it with Windows Defender and publishes SHA-256 checksums.

## Download

Replace the earlier preview executable with this stable build while keeping your existing configuration and recordings.

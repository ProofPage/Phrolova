# Phrolova v2.1.9

Adds support for YamiKorea, AV19, and MissAV video downloads with robust security validation and accurate media extraction.

## New Platforms

- **YamiKorea (`ym-05.com`)**:
  - Supports individual video downloads from `https://ym-05.com/videos/<slug>/`.
  - Automatically isolates and extracts the primary MP4 media stream, strictly excluding pre-roll advertisement clips and thumbnail preview videos.
- **AV19 (`av19t.com`)**:
  - Supports individual video downloads across all three categories: `/korea/<id>`, `/bj/<id>`, and `/nsub/<id>`.
  - Employs a hash-pinned, sandboxed WASM decoder bridge to process session-key envelopes (versions 10 and 11) into standard AES-128 keys without remote JavaScript execution.
  - Downloads and finalizes standard MPEG-TS segments without arbitrary byte stripping.
- **MissAV (`missav123.com`)**:
  - Supports individual video downloads from `https://missav123.com/ko/<slug>`.
  - Resolves packed main-player HLS stream configurations and downloads clean, unencrypted MPEG-TS segments with user-selected resolution options.
  - Rejects navigation/listing pages (such as `/dm270/ko`) and stops safely without automated mirror switching or challenge circumvention.

## Compatibility and Verification

- Full backend regression test suite passed (**2,238 tests**).
- Frontend multi-locale validation (8 languages), URL contract tests, and production build passed.
- Windows packaged executable builds cleanly with bundled Node.js and AV19 WASM decoder bridge.

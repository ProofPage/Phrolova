# Phrolova v2.0.80-preview.15

Preview release adding native HearHeart (`hearheart.com`) platform support for VOD, playlist, and audio-drama downloads.

### Key Changes
- **Native HearHeart (`hearheart.com`) Platform Support**:
  - Implemented custom yt-dlp `HearHeartIE` extractor resolving secured HLS (`.m3u8`) video streams from authenticated `videoPlayer` components.
  - Supports individual episode downloads via `https://hearheart.com/playlist/{playlist_id}/play/{content_id}` and bulk series extraction via `https://hearheart.com/playlist/{playlist_id}`.
  - Integrated HearHeart cookie file management in Settings -> Authentication tab to download 19+ adult and subscriber-only content seamlessly.
  - Added HearHeart brand badge styling (`#ff2777`) and automatic clipboard URL detection in the VOD download tab.

- **Inherited from Earlier Previews**:
  - Fixed TikTok live preview video player startup stalled by non-zero FLV stream PTS.
  - Dedicated video player for TikTok live previews without static frame fallbacks.
  - Encapsulated pure ES module packaging for `mpegts.js`.
  - Prioritized browser-compatible H.264 video streams for TikTok live previews.
  - Fixed SQLite `recording_jobs.source_path` unique constraint collision on recording restart.
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

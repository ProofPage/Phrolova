# Version 2.0.62

## 기본 설정 UI·UX
- 라이브·동영상 화면과 같은 입력칸, 화질·형식 선택 상자와 버튼을 사용합니다.
- 저장 경로가 한 줄이면 입력칸 높이를 간결하게 유지하고 글자를 세로 가운데에 표시합니다. 긴 경로는 줄바꿈에 맞춰 높이를 자동으로 조절하며 확인 단계에서도 전체 경로를 표시합니다.
- 폴더 선택 버튼의 높이와 정렬을 입력칸에 맞추고, 폴더 선택창이 설정 화면의 스크롤 영역에 잘리지 않도록 수정했습니다.
- 단계 안내는 현재 단계를 밑줄로 표시하며, 작은 화면과 가로 화면에서도 이전·확인·완료 버튼을 계속 사용할 수 있습니다.
- ‘영상 저장 위치’를 ‘동영상 저장 위치’로 통일했습니다. 폴더 자동 생성 안내는 ‘저장 위치’ 제목 아래로 옮기고 제목 앞의 폴더 아이콘을 제거했습니다.
- 단계 전환 시 키보드 초점을 제목으로 옮기고, 저장 중에는 이전 이동과 중복 제출을 막습니다. 저장 실패 시 입력을 유지해 다시 시도할 수 있습니다.

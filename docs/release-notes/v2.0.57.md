# Version 2.0.57

## Preview recovery

- Fix TLS certificate validation for nested CIME HLS requests. Preview-only HTTPS ingestion validates system/Mozilla certificate authorities before FFmpeg decodes the media.
- Add error-specific retries, backoff, manual retry and last-good-frame guidance.
- Coalesce duplicate frame generation and clean up processes/timers when channels are deleted or go offline.
- Proxy CHZZK/YouTube HLS previews without exposing signed source URLs to the browser; mask diagnostic logs.
- Stabilize SOOP/CIME preview layout during failure and recovery.

## Tools and file processing

- Discover and execute FFmpeg/FFprobe independently; install both executables together during Windows automatic tool setup.
- Show tool status, installation/custom-path guidance and recheck actions in System settings.
- Distinguish missing FFprobe from inspection/conversion failures. Keep source data and allow reinspection/reconversion after installation.
- Verify original-file/folder actions, reinspection, reconversion and MKV fallback. Remote folder requests return the server path.

## Downloads and shared UI

- Do not complete downloads with skipped fragments; bound fragment concurrency/backoff and retry metadata timeouts.
- Mask signed URLs and credentials in download failures/logs across platforms.
- Improve preview, toast and copy-notification cleanup and error handling.
- Preserve Streamlink/yt-dlp engines, TS-first capture, default MKV processing and user data.

## Validation

- Windows, Ubuntu x64 and Ubuntu ARM64 CI: 790 passed, 2 skipped and 4 subtests passed on each runner.
- Local Windows: 791 passed, plus a real TS larger than 3 GiB with a Korean path.
- TypeScript/build/Python checks, ten viewport widths, preview recovery and download/settings/processing regressions passed.
- Real public CIME 1920×1080 and SOOP 960×540 preview frames were generated.

FFmpeg/FFprobe remain external. Install both and recheck the tools. Android Termux, Windows 10 devices and long-duration load were not tested for this release.

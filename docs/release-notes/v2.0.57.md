# Version 2.0.57

## 라이브 미리보기 복구
- CIME의 중첩 HLS 요청에서 발생하던 TLS 인증서 검증 실패를 수정했습니다. 미리보기 전용 HTTPS 수신은 시스템·Mozilla CA를 검증하며 FFmpeg는 수신 영상을 디코딩합니다.
- 미리보기 오류별 자동 재시도·백오프·수동 재시도와 마지막 정상 화면 안내를 추가했습니다.
- 중복 프레임 생성, 채널 삭제·방송 종료 시 자식 프로세스와 타이머 정리를 보강했습니다.
- CHZZK/YouTube의 HLS 미리보기는 서버 프록시를 통해 재생합니다. 서명 URL을 브라우저에 전달하지 않으며 진단 로그도 마스킹합니다.
- SOOP/CIME 미리보기 실패·복구 시 표시 영역과 카드 정렬을 안정화했습니다.

## FFprobe 및 녹화 후처리
- FFmpeg와 FFprobe를 독립적으로 탐색하고 실제 실행 가능 여부를 검사합니다. Windows 자동 도구 설치 시 두 실행 파일을 함께 배치합니다.
- 시스템 설정에 미디어 도구 상태·설치·사용자 경로 안내와 다시 검사 버튼을 추가했습니다.
- FFprobe 누락과 파일 검사·변환 실패 단계를 구분해 표시합니다. 실패한 원본은 보관하고 설치 후 재검사·재변환할 수 있습니다.
- 원본 파일 열기·폴더 열기·재검사·재변환·MKV 대체 경로를 검증했습니다. 원격 브라우저의 폴더 요청은 서버 저장 경로를 안내합니다.

## 다운로드 및 공통 UI
- 누락된 다운로드 fragment를 건너뛰어 완료 처리하지 않도록 했습니다. fragment 동시성·재시도 백오프와 메타데이터 timeout의 제한 재시도를 보강했습니다.
- 모든 플랫폼의 다운로드 오류 및 로그에서 서명 URL·인증 정보를 마스킹합니다.
- 미리보기 이미지, 토스트와 복사 알림의 타이머 정리 및 오류 처리를 개선했습니다.
- Streamlink 라이브 녹화, yt-dlp VOD, TS 우선 수신, 기본 MKV 후처리와 기존 설정·DB·파일을 유지합니다.

## 검증
- Windows·Ubuntu x64·Ubuntu ARM64 CI: 각각 790개 통과, 2개 제외, 하위 테스트 4개 통과.
- 로컬 Windows 전체 회귀: 791개 통과. 별도 3GiB 초과 실제 TS·한글 경로 검사 통과.
- TypeScript 검사·프런트엔드 빌드·Python 오류 검사 통과.
- 10개 화면 폭의 그리드·목록 미리보기 실패·복구 및 다운로드·설정·후처리 브라우저 회귀 통과.
- 공개 CIME 1920×1080 및 SOOP 960×540 실제 프레임 생성 확인.

FFmpeg/FFprobe는 실행 파일에 포함하지 않습니다. 기존 FFmpeg만 설치된 환경은 같은 bin 폴더에 FFprobe도 설치하고 시스템 설정에서 다시 검사하세요. Android Termux 실기, Windows 10 실기와 장시간 부하 검증은 수행하지 않았습니다.

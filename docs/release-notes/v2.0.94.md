# Phrolova v2.0.94

## VOD download input simplification
- Replaced the multiline textarea with a single-line input field for VOD/clip URL entry.
- Pressing Enter in the input field now automatically submits and starts the download.
- Updated input guidance text across all 8 supported languages to remove "separate multiple links with line breaks".

## Bitrate calculation stability
- Prevent momentary calculation spikes (e.g. 200–300 Mbps) during the first 3 seconds of a live recording when media duration is near zero. Bitrate display remains clean and accurate.

## Validation
- Frontend build, TypeScript checks, and all 8 locale audits passed.
- Release metadata tests passed.

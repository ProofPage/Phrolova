# Version 2.0.63

## 8개 언어 지원
- 한국어, English, 日本語, Español, Deutsch, 简体中文, 繁體中文, Русский를 지원합니다. 각 언어에 807개 번역을 제공합니다.
- 설정 → 외관에서 언어를 선택하면 재시작 없이 전체 화면에 적용되며, 다음 실행에서도 선택을 복원합니다. 기본 언어는 한국어입니다.
- 라이브·동영상·통계·시스템 로그·설정, 기본 설정 마법사, 팝업·알림·접근성 이름과 동적 상태를 현지화했습니다.
- 날짜·숫자·단위·복수형을 언어에 맞게 표시합니다. 플랫폼 이름과 기술 식별자, 경로·파일명·사용자 콘텐츠·기술 로그는 유지합니다.

## UI와 미리보기 수정
- 언어 설정 연결 및 번역 리소스 자동 갱신 중 발생하던 개발 미리보기의 빈 화면을 수정했습니다.
- 긴 번역이 카드 밖으로 밀리지 않도록 녹화 버튼·상태·수치 레이블·파일 검사 배지의 줄바꿈을 보완했습니다.
- 정보 탭에 Streamlink·FFmpeg·FFprobe 정상 여부와 설치 경로, 도구 재검사를 같은 형식으로 배치하고 서버 주소 표시를 제거했습니다.
- 업데이트 정보 조회 실패와 미조회 상태를 구분하고, 인증·파일 검사·녹화/다운로드 오류 및 기존 알림 내역을 선택 언어로 표시합니다.

## 기존 동작 유지
- 기존 설정, 저장 경로와 사용자 데이터를 유지합니다. Streamlink 녹화, TS/fMP4 원본 처리, FFmpeg 후처리, MKV 기본 완료 형식과 MP4 선택, 다운로드 엔진을 변경하지 않았습니다.
- HTTP 오류에 표시용 키를 추가하면서 기존 detail, 상태 코드와 헤더를 보존합니다.
- 삭제한 X Spaces·채팅 기록·라이브 채팅 저장 기능을 추가하지 않았습니다.

## 검증
- 백엔드 전체: 886 passed, 1 skipped, 4 subtests passed. 별도 활성화가 필요한 3 GiB 초과 TS 생성 검사 1개만 건너뛰었습니다.
- TypeScript 검사와 제품 빌드, 8개 언어 각 807개 리소스의 누락·빈 값·중복·변수 검사 통과.
- 8개 언어 × 전체 5개 페이지와 설정 하위 탭, 320/390/1440px, 언어 즉시 변경·복원, 기본 설정·녹화·업데이트 팝업과 기존 알림 갱신 검사 통과.
- 번역 자동 갱신, 기본 설정·설정 저장/복구·정보 도구·녹화 카드·다운로드 회귀 검사 통과.

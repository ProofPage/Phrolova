# Version 2.0.15

## CHZZK live recording and Time Machine

- Added standard, request-Time-Machine, and force-Time-Machine recording modes with configurable offsets and fallback behavior.
- Improved live output naming, thumbnail handling, and TS/MKV/fragmented MP4 recording.

## CHZZK VOD downloads

- Relaxed network and fragment timeouts and retries for long VODs.
- Added Akamai/Naver CDN fallback, including rewriting Naver segment hosts to `light-slit.akamaized.net` while preserving signed URLs.
- Validate downloaded duration and retry incomplete results; use scoped temporary cookie files with yt-dlp.

Download the Windows x64 executable and replace the existing Rookery.exe. Settings and saved data are preserved.

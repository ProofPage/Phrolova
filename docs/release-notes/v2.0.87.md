# Phrolova v2.0.87

This release makes YouTube runtime preparation visible at startup and fixes authentication layout and interaction issues.

## YouTube startup and automatic provider

- Prepare Deno 2.9.7, bgutil server 2.0.2 and its matching yt-dlp plugin before application startup completes.
- Send setup messages to both the shared console and service log. Show six installation/check stages, installation reuse and the failing stage.
- Verify pinned SHA-256 hashes and reuse healthy installations instead of downloading again.
- Leave the PO Token Provider URL blank to automatically prepare and connect to `http://127.0.0.1:4416`. The default URL, with or without a trailing slash, also uses the managed local server.
- Fix clearing a custom provider URL: saving an empty field now restores automatic mode instead of retaining the previous address.
- Preserve separate external provider settings, reuse matching local servers, bind owned servers to loopback and stop only app-owned processes.
- Setup failures are reported as warnings and are not marked successful; other platforms can remain available after the preparation result is known.

Initial installation needs internet access and may take several minutes. Runtime/provider readiness does not guarantee that YouTube accepts an account, cookies or network connection.

## Authentication screen

- Stack desktop cards in two independent columns so opening a card does not create empty space in the opposite column. Keep one column on mobile.
- Add the missing RPLAY key icon and translate RPLAY error messages.
- Trim RPLAY sign-in email, retain password clearing and block authentication-method switching during active requests.
- Show failed initial status checks rather than leaving the badge indefinitely at “checking.”
- Explain automatic versus custom provider URLs in all eight interface languages.

## Validation and download

- Browser regression with isolated API fixtures covered login forms, failures, request locking, password clearing, keyboard interaction and 320–1440px layouts.
- Windows tool downloads, pinned hash checks, plugin loading, an existing matching provider response and restart without reinstallation were verified.
- TypeScript, production build and eight-language checks passed; the existing bundle-size warning remains.
- Real-account sign-in success and resolution of YouTube bot verification are separate from these checks.
- Download `Phrolova-v2.0.87-windows-x64.exe` and verify its SHA-256 against `SHA256SUMS.txt`. Publication is performed by the Windows build and Defender-scan workflow.

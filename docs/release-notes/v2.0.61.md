# Version 2.0.61

## 숲 라이브 시청자 수
- 공식 채널 API의 현재 방송 시청자 수를 표시합니다.
- 방송 번호를 확인해 이전 방송의 시청자 수가 섞이지 않도록 하고, 실제 0명과 방송 시작 시각을 보존합니다.
- 선택 메타데이터 조회가 실패해도 라이브 녹화를 계속할 수 있도록 처리합니다.

## 동영상 화면
- 사이드바 메뉴와 페이지 제목을 ‘동영상’으로 변경했습니다.
- 라이브와 동영상의 플랫폼 선택 버튼을 같은 기준으로 정렬했습니다.
- 상단 바의 다운로드 개수·진행률 표시를 제거했습니다.
- 완료 카드의 파일·폴더 버튼 높이·테두리·간격을 맞췄습니다.
- ‘파일 검사 완료’는 별도 배지로 표시하며, 상단 상세보기 버튼 왼쪽에 배치했습니다. 모바일에서도 제목과 버튼이 겹치지 않도록 정리했습니다.

## 정보 설정 통합
- 시스템 탭을 제거하고 미디어 도구 검사와 프로그램 업데이트를 정보 탭으로 통합했습니다.
- 버전 표시 중복을 정리하고 업데이트 표시·시스템 정보·제작자·저장소·라이선스 정보를 유지했습니다.

# Phrolova v2.0.80-preview.6

Preview release resolving remux duration inspection errors and enhancing Streamlink live queue deadlines on RPLAY streams.

### Key Changes
- **Tolerate Duration Normalization from TS Timestamp Discontinuities**:
  - Live streams with timestamp discontinuities (such as RPLAY HLS) often produce TS containers whose ffprobe duration appears artificially elongated (e.g. 700+ seconds due to non-zero starting PTS offsets).
  - Stream-copy conversion to MKV/MP4 normalizes PTS/DTS offsets starting at 0, yielding the true playback duration (e.g. 22 seconds).
  - Remux inspection now recognizes FFmpeg timestamp discontinuity warnings and avoids false-positive "원본과 변환 파일의 길이가 다릅니다" errors.

- **Strengthen Streamlink Live Queue Deadline**:
  - Increased `stream-segmented-queue-deadline` factor to prevent premature live stream termination during minor segment generation delays on dynamic broadcasts.

- **Inherited from Earlier Previews**:
  - Instant CHZZK preview resolution via official time-machine endpoint without transient 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.
  - Preview buffering elimination by trimming massive time-shifted playlists.

# Phrolova v2.0.89

## Fixed
- Recognize the observed Anime24 episode CDN hosts: `fri1bcloud-starcdn.xyz` through `fri7bcloud-starcdn.xyz`, and `hol1ncloud1-nocdn.xyz` through `hol7ncloud1-nocdn.xyz`.
- Keep HTTPS, redirect, private-address and exact-host validation in place. Lookalike domains remain blocked.

## Removed
- Remove TVCHAK from download selection, authentication, URL recognition, API registration, extraction and current documentation.
- Existing downloaded files, task records and credential files are not deleted.

## Compatibility
- Preserve the existing application interface. The rejected NanaCast-inspired design prototype is not included.
- Preserve the Deno and bgutil installation locations introduced in v2.0.88.

## Validation and download
- Episode regression coverage includes the observed CDN hosts and rejection of spoofed hosts. Short real-media validation confirmed 1080p video and audio; full-episode downloading was not verified.
- Download `Phrolova-v2.0.89-windows-x64.exe` and verify it against `SHA256SUMS.txt`. Publication requires a Windows build and Defender scan.

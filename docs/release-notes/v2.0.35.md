# Version 2.0.35

## Notifications, Chat Logs, and Replay Filenames

- Added a "Clear all" action to the notification center. It clears notification history and currently displayed notifications.
- Standardized the navigation labels as X Spaces and Chat Logs.
- Added a refresh action, section heading, and empty-state guidance to Chat Logs.
- Added a replay filename template setting. It applies to new downloads and CHZZK clips.
- Default template: `[{name}] {title} {date_year}-{date_month}-{date_day} {date_hour}-{date_minute}-{date_second}`
- The date and time use the download start time. The file extension is added automatically.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

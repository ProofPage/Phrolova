# Phrolova v2.0.80-preview.9

Preview release introducing real-time video playback for TikTok live streams using `mpegts.js`.

### Key Changes
- **Real-Time Video Player for TikTok Live Previews**:
  - Replaced static keyframe image polling on TikTok live previews with real-time video and audio streaming via browser-side `mpegts.js`.
  - Upstream HTTP-FLV stream is piped through the proxy as chunked video stream (`video/x-flv`) with TikTok origin and referer headers.
  - Video player features smooth sub-second playback, volume controls, mute/unmute, and full-screen modes with automatic fallback to frame snapshot preview if browser MSE is unsupported.

- **Inherited from Earlier Previews**:
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

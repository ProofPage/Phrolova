# Version 2.0.32

## Watch-Along Detection Fixes

- Checks CHZZK's official watch-along information, even when a regular stream's tags do not include "watch-along."
- Fixed an issue from v2.0.31 that allowed official watch-along streams through the "Exclude watch-alongs" condition.
- Shows the official watch-along status and content tags in the settings dialog.
- Records why an automatic recording was put on hold in the logs.

## Tag Input by Recording Condition

- Hides the tag field and allows saving without tags for "Record all live streams" and "Exclude watch-alongs."
- "Exclude watch-alongs" excludes every watch-along regardless of the selected tags.
- Tags can be entered only for "Only record watch-alongs." The "watch-along" tag selects all watch-alongs; a specific content tag narrows the selection.
- These rules apply to both dashboard defaults and per-channel settings.

Condition changes take effect the next time automatic recording starts. Recordings already in progress and manual recording remain unchanged.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

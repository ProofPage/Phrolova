# Phrolova v2.0.80-preview.11

Preview release prioritizing browser-compatible H.264 video streams for TikTok live previews.

### Key Changes
- **Serve Browser-Compatible H.264 for TikTok Previews**:
  - TikTok live streams often offer H.265 (HEVC) for origin/1080p60 resolutions, which standard browser MediaSource Extensions (MSE) cannot decode inside an FLV container, triggering an error that caused the player to fall back to static image mode.
  - `TikTokLiveEngine.resolve_preview_stream` now specifically prioritizes H.264 (AVC) variants (e.g. `h264_hd`) for previews while preserving user-selected maximum quality (H.265 1080p60) for recordings.
  - Delivers seamless, uninterrupted real-time video and audio playback via `mpegts.js`.

- **Inherited from Earlier Previews**:
  - Fix SQLite `recording_jobs.source_path` unique constraint collision on recording restart.
  - Real-time video player for TikTok live previews via `mpegts.js`.
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

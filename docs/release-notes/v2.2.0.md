# Phrolova v2.2.0

## Highlights

- **Automatic Live-First Channel Sorting**: Channels that go live automatically move to the top of the dashboard, sorted alphabetically by channel name.
- **Robust YouTube Live & VOD Handling**: Fixed DASH CDN redirect interruptions, support for `/live/` and `/shorts/` URLs, and eliminated false reconnect warnings on offline channels.
- **Universal Cookie Management**: Support for Cookie-Editor `#HttpOnly_` exports, direct cookie text pasting, and one-click import from local browsers across all supported platforms.
- **Expanded Platform URL Support**: Added support for CHZZK mobile links (`m.chzzk.naver.com`), RPLAY creator home URLs (`/creatorhome/<id>`), and custom creator handles (`/c/<handle>`).

---

## Detailed Changes

### 1. Dashboard & Channel Organization
- **Live-First Auto Sorting**:
  - Live and recording channels automatically sort to the top of the channel list.
  - Channels within the live and offline groups are sorted alphabetically by channel name.
  - Added a sort mode selector to the dashboard toolbar:
    - **Live first (by name)** (*Default*)
    - **Name**
    - **Manual order** (with drag-and-drop and arrow reordering)

### 2. YouTube Live & Video Engine
- **CDN Redirection Resilience**:
  - Fixed `RecordingError: 유튜브 CDN 주소가 변경되었습니다` by dynamically following HTTP 302/307 load-balancing redirects to new Google Video edge nodes in `youtube_dash.py`.
- **URL Normalization**:
  - Full support for `youtube.com/live/<id>`, `youtube.com/shorts/<id>`, `youtu.be/<id>`, and `watch?v=<id>`.
  - Prevents malformed `@https://...` channel keys and automatically migrates legacy database entries.
- **Accurate Offline Status Detection**:
  - Correctly recognizes `The channel is not currently live` and `does not have a live stream` as clean offline states rather than connection errors.
  - Added strict `channelId` cross-validation to prevent false positives from YouTube's generic live recommendation feeds.

### 3. Cookie Management & Platform Authentication
- **Cookie-Editor `#HttpOnly_` Support**:
  - Netscape cookie parsers now automatically strip `#HttpOnly_` comment prefixes from exported cookie files (e.g., Naver `NID_AUT`).
- **Direct Cookie Text Pasting**:
  - Added a modal to paste raw cookie headers (`Cookie: ...`), Netscape text, or credentials directly without saving to a `.txt` file.
- **One-Click Browser Cookie Import**:
  - Automatically imports logged-in platform sessions directly from installed browsers (Chrome, Edge, Whale, Brave, Firefox).
- **Accurate Session Verification**:
  - Real-time session verification with clear status badges (`Logged in`, `Cookies registered`, `Cookie expired`).

### 4. RPLAY & CHZZK Enhancements
- **CHZZK**:
  - Full support for mobile URLs (`https://m.chzzk.naver.com/<channel_id>`).
- **RPLAY**:
  - Support for custom creator handle URLs (`https://rplay.live/c/<handle>`) with automatic 24-character OID resolution and caching.
  - Support for creator home URLs (`https://rplay.live/creatorhome/<id>`).
  - Fixed 404 routing error when requesting stream quality options with encoded URLs.

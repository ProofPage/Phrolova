# Phrolova v2.2.0

Adds automatic resolution for RPLAY custom creator URLs (`https://rplay.live/c/<handle>`).

## Changes

- **RPLAY Custom Creator URLs**:
  - Live channel monitoring now directly accepts creator handle links such as `https://rplay.live/c/hitsu`, `https://rplay.live/c/tsuki`, and `https://rplay.live/c/seldea?page=creator-home`.
  - Automatically resolves and caches the creator's 24-character hexadecimal OID from official public page metadata.
  - Full backwards compatibility with 24-character IDs and `https://rplay.live/live/<id>` URLs is preserved.

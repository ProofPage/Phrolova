# Version 2.0.39

## Log and Copy Improvements

- Separated general logs from logs for YouTube, CHZZK, TwitCasting, and X Spaces.
- Added platform names to download-tool error logs.
- Refined notification wording for downloads, completions, and failures, along with Phrolova branding.
- Fixed platform logs so they continue to be recorded after the logs are cleared.

This release contains log and wording updates. It does not include feature improvements listed in the analysis report.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

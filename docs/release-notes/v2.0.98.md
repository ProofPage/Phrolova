# Phrolova v2.0.98

## RPLAY Playlist Reload 500 Server Error Fix
- Resolved transient `Reloading failed: Unable to open URL: (500 Server Error)` logs during RPLAY livestream recording.
- Streamlink's `reload_attempts` option is now fully respected during playlist fetches instead of being constrained to a single attempt.
- On transient CDN 5xx errors (500, 502, 503, 504), RplayWorker now automatically fetches fresh stream credentials and retries smoothly without exposing error noise.

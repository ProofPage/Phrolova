# Version 2.0.34

## Recording Condition Guidance When Automatic Recording Is Off

- Shows why a live stream does not meet the configured recording conditions, even when automatic recording is turned off.
- Distinguishes "Recording on hold" when automatic recording is on from "Condition guidance" when it is off.
- Applies to both "Only record watch-alongs" and "Record all live streams except watch-alongs."
- Shows the same guidance in card and list views, and refreshes it immediately when the automatic-recording toggle changes.
- Keeps condition guidance separate from automatic recording. Turning automatic recording off will not start a recording.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

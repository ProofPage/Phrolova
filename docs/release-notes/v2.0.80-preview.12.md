# Phrolova v2.0.80-preview.12

Preview release ensuring pure ES module instantiation for `mpegts.js` and resilient real-time TikTok player startup.

### Key Changes
- **Clean ES Module Packaging for `mpegts.js`**:
  - Encapsulated `mpegts.js` factory invocation into a self-contained ES module export to guarantee that `mpegts.createPlayer` and `mpegts.isSupported()` evaluate reliably across Vite production bundles without evaluating as undefined in strict-mode scopes.
  - Increased recovery retry tolerance and added diagnostics for video element initialization to prevent inadvertent premature fallback to static image frames.

- **Inherited from Earlier Previews**:
  - Prioritized browser-compatible H.264 video streams for TikTok live previews.
  - Fixed SQLite `recording_jobs.source_path` unique constraint collision on recording restart.
  - Real-time video player for TikTok live previews via `mpegts.js`.
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

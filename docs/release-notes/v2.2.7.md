# Phrolova v2.2.7

## SOOP support and reliability

- Add SOOP live channel monitoring, recording, VOD sources, and authentication settings.
- Validate channel and VOD links, preserve domain-scoped cookies, and distinguish channel lookup failures from offline broadcasts.
- Resolve live preview manifests and supply the required SOOP playback headers through the preview proxy.
- Close stream discovery sessions after use and report unavailable quality selections instead of silently changing quality.

## Optional fallback downloader

- Keep yt-dlp as the primary VOD downloader and invoke N_m3u8DL-RE independently only after an eligible, already-resolved single HLS VOD download fails.
- Preserve cancellation, avoid overwriting existing output, and retain the normal output verification path.
- Do not retry authentication failures or DRM-protected content through the fallback downloader.
- Require cookie-file support in N_m3u8DL-RE before passing domain-scoped authentication cookies.
- Offer N_m3u8DL-RE installation during interactive startup checks and detect its standard installation directory.

## Live stream quality and metadata

- Display actual video dimensions and frame rates (such as `1920×1080 · 60fps`) in recording details whenever verified stream metadata is available.
- Retrieve live HLS renditions for CHZZK channels and display real resolution and FPS details alongside quality names in the selection menu.
- Relay stream rendition metadata seamlessly across CHZZK, CIME, Kick, Twitch, TikTok, Bilibili, PandaTV, PopkonTV, and RPLAY pipelines.
- Preserve explicit quality selections and fall back gracefully without guessing resolution or frame rates when stream metadata is unavailable.

## Channel configuration and interface alignment

- Remove the icon beside the channel configuration modal title for a clean, consistent header.
- Unify layout, spacing, and alignment across weekday checkboxes, time inputs, and action buttons in scheduled monitoring.
- Correct mobile and narrow-viewport navigation trigger positioning so the menu icon aligns with topbar search controls.
- Remove the topbar notification icon and notification center.

## Dependency handling and installation paths

- Prioritize Python packages for yt-dlp and Streamlink, eliminating unnecessary external executable downloads and preventing unexpected creation of `bin` folders.
- Automatically search standard Windows installation directories for FFmpeg and FFprobe (`%LOCALAPPDATA%\Programs\ffmpeg\bin`, WinGet, Chocolatey, Scoop, and `C:\Program Files`).
- Automatically detect and use user-extracted versioned folders (`ffmpeg-*`) in standard user and download locations.
- Install FFmpeg and FFprobe into the standard Windows user program directory (`%LOCALAPPDATA%\Programs\ffmpeg\bin`) when automated download is accepted.

## Authentication settings

- Include the refined authentication layout with border and corner treatment matching adjacent cards.
- Use the full content width for the platform list before selection, and split into equally balanced panels once a platform is chosen.
- Restore the full-width list upon closing authentication settings.

## Update behavior

- Program updates remain notification-only; automatic background installation and restarts at startup are disabled.
- Preserve update checks and manual release notices without installing external tool updates automatically.
- Do not open a browser automatically at startup; retain the manual browser action in the system tray.

## Interface consistency

- Match storage location and disk usage panels to shared card tokens and section header styles.
- Align log summary and inspection card dividers and padding with adjacent panels.

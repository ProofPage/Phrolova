Add episode-based video downloads for Anilife, Linkani and Ohli24, and fix missing platform choices when the download-source request fails.

## Episode-based videos

- Adapt the supplied Lua plugin rules into native Python extractors for the existing yt-dlp pipeline. No Lua runtime or uploaded script execution is required.
- Add Anilife, Linkani and Ohli24 to Videos while preserving CHZZK, YouTube, SOOP, CIME, Kick, Twitch, TikTok and external video sources.
- Paste a work or episode link, search the episode list, and select up to 100 episodes. The picker includes pagination, unavailable-file status and a notice when the site omits earlier episodes.
- Add each selected episode to the existing download queue with actual advertised quality options, task controls, saved history, FFmpeg finalization and FFprobe inspection. Save validated VTT subtitles alongside the video.
- Verify work/episode identity and Ohli24 parent links. Parse normal player JSON without evaluating site JavaScript.
- Keep normal player-issued cookies scoped to the extraction/download session. Check HTTPS hosts and redirects against explicit allowlists and bound metadata response sizes.
- Accept ordinary HLS AES-128 identity keys and reject malformed, duplicate or unsupported/protected key attributes, advertising playlists and unfinished live media.

## Interface and compatibility fixes

- Keep the full download-source list when the capability endpoint fails; display a connection error and retry action instead of silently falling back to three choices.
- Encode Unicode paths correctly in Referer headers, preserve only verified episode entries and support the current Ohli24 CDN hosts observed in its issued playlist.
- Add source labels and episode controls to all eight interface languages. Check the picker and source list on narrow mobile screens.

## Upgrade

Finish active recordings/downloads and stop Phrolova before replacing the executable. Preserve your `.env`, `data` directory and media. Source installations should update dependencies; Termux uses `backend/requirements-termux.txt`.

Open Videos, choose Anilife, Linkani or Ohli24 and paste a supported work/episode URL. Work links open the episode picker before tasks are queued. See [episode source documentation](https://github.com/ProofPage/Phrolova/blob/v2.0.70/docs/video-site-adapters.md) for URL formats and validation details.

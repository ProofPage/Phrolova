# Version 2.0.37

## Localization and Download Improvements

- Added Korean, English, and Japanese language selection and translated key screens. The selected language is saved and restored.
- You can enter a YouTube channel URL, handle, or channel ID to add its videos to the download queue.
- Refined the platform selector and queue information on the replay download page.
- Disabled JSONL chat logging by default during recordings and kept the delete-channel button visible in both card and list views.

Replace the existing application executable with the Windows x64 build to update. Your settings and saved data are preserved.

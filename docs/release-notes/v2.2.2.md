# Phrolova v2.2.2

## New platforms

- Added Spoon public live audio monitoring and recording, including channel URLs, user tags, and live links.
- Spoon recordings preserve the original audio stream. Reconnection creates separate parts rather than concatenating damaged sessions.
- Added Berriz community live monitoring and authorized non-DRM HLS recording.
- Added Berriz non-DRM live replay downloads and cookie registration under authentication settings.
- DRM-protected Berriz content is not supported.

## Integration

- Added platform selection, input normalization, quality selection, and translated platform labels.
- Reject unsupported media addresses and keep authentication credentials scoped to their platform.

## Validation

- Backend regression suite: 2,294 passed, 2 skipped on standard-GIL Python 3.14.8.
- Frontend production build and all eight locale checks passed.
- Berriz live recording uses mocked playback responses; an active Berriz broadcast was not available for end-to-end recording verification.

Add TVWiki video downloads and restore YouTube live recordings that use separate video and audio streams.

## Changes

- Add **TVWiki (티비위키)** to Videos. Paste work or episode links for dramas, shows, movies and animation; select episodes with the existing search, pagination and queue controls. Preserve all 13 download sources, platform badges, scoped logs and eight-language labels.
- Follow TVWiki's normal guest/player session and advertised native HLS rendition. Keep cookies within each task, validate standard 16-byte AES-128 keys, and use the existing native downloader, local remuxing and media inspection.
- Recover failed TVWiki CDN fragments from their issuing media server. Retry only exact resources advertised by the validated playlist, preserve path/query, strip explicit cross-host credentials and avoid repeatedly contacting a failed CDN host. Missing fragments are never silently skipped.
- Fix YouTube live format selection when no combined video/audio HLS rendition exists. Pass the master playlist to Streamlink so the requested quality and its audio rendition remain connected.
- Preserve YouTube ID3v2.3 audio data instead of terminating capture in Streamlink's ID3v2.4-only parser. Finalize the closed video/audio source files together without re-encoding.
- Align Windows packaging with the current repository by removing stale references to deleted project documents.

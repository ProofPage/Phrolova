# Phrolova v2.0.80-preview.27

SOOPStreamer 에이전트의 원본 1080p WebSocket 스트림을 Phrolova 녹화 파이프라인에 연결했습니다.

### Key Changes
- SOOPStreamer 동적 에이전트 포트에서 원본 H.264 스트림을 수신합니다.
- 에이전트 전용 바이너리 블록 헤더와 오디오 프레임을 제거해 Phrolova가 처리할 수 있는 H.264 elementary stream으로 저장합니다.
- 실제 Phrolova 녹화 파일에서 `1920x1080` 해상도를 검증했습니다.

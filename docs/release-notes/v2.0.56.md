# Version 2.0.56

## 치지직 라이브 수신 안정화
- Chzzk-Rekoda의 LL-HLS 연속 수신 개선을 Phrolova의 Streamlink 녹화 구조에 맞춰 적용했습니다.
- 국내 CDN을 우선 사용하고, 실제 재생 구간과 초기화 데이터가 확인된 Akamai CDN을 대기 경로로 준비합니다.
- 공개된 부분 세그먼트만 수신하고, 누락·불완전한 구간은 전체 세그먼트로 복구합니다. 복구 제한 시간과 종료 처리를 추가했습니다.
- 초기화 데이터가 변경되는 경계에서는 기존 파일을 종료하고 새 녹화 파일과 작업을 생성합니다. 진행 중 녹화의 화질과 저장 정책은 유지합니다.
- Streamlink 원본 녹화와 종료 후 FFmpeg 변환·FFprobe 검증을 유지합니다. TS를 우선 사용하며 fMP4 방송은 실제 원본 형식으로 저장합니다.
- 녹화 상세에 수신 CDN과 대기 경로 상태를 표시합니다. 인증 정보와 스트림 URL은 진단 이벤트에 포함하지 않습니다.

## 카드 정렬 수정
- 라이브 미리보기를 펼쳐도 옆의 접힌 카드가 같은 높이로 늘어나지 않도록 수정했습니다.
- 다운로드 그리드의 불필요한 빈 공간을 제거하고, 같은 행의 카드 높이와 하단 버튼 기준선을 맞췄습니다.
- 대기 카드의 화질 선택과 다운로드 시작 버튼도 다른 카드와 같은 하단 기준선에 배치합니다.

## 검증
- Python 회귀 테스트: 746개 통과, 6개 제외, 추가 하위 테스트 4개 통과.
- TypeScript 검사 및 프론트엔드 빌드 통과.
- 라이브·다운로드 반응형 브라우저 검사와 다운로드 제어 회귀 검사 통과.
- 공개 치지직 방송의 일반·강제 타임머신 녹화, MKV 변환 및 FFprobe 검사 통과.

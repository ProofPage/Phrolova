# Phrolova v2.2.4

## Interface clarity

- Remove duplicate page icons and titles from the top bar.
- Remove redundant separators from cookie authentication panels.
- Give settings categories and authentication platform lists opaque backgrounds and clearer selection borders.
- Improve separation between live recording cards, download cards, log file lists, and log content.
- Use solid surfaces for shared workspace controls and dialogs.
- Keep desktop settings categories visible while scrolling.
- Remove repeated authentication guidance and make instructions independent of panel position in all eight languages.
- Improve Korean word wrapping in settings help and authentication actions.
- Give disabled primary actions a neutral appearance.

## Recording recovery

- Preserve already completed CDN fallback downloads when the polling thread resumes after the recovery deadline.
- Keep the existing recovery timeout for unfinished requests and add deterministic scheduler-pause coverage.
- Treat empty RPLAY media segments as retryable connection failures instead of successful writes.
- Consume late receiver failures during startup timeout or cancellation without orphaned shielded-future errors.

## Validation scope

Responsive regression tests cover five routes at 375, 768, and 1440 pixels, authentication controls, keyboard dismissal and focus restoration, and accessibility preferences. Log regression tests cover eight languages and four viewport widths.

Interactive review covered navigation, filters, authentication panel opening and closing, download help, statistics refresh, log search, and mobile navigation. It did not run real downloads, change recording state, or verify real-account sign-in.

The Windows executable is published only after the release workflow passes regression tests, packaging, and a Windows Defender scan.

# Version 2.0.64

## Settings and navigation

- Save video, recording-file processing and live settings through one bottom-right Save Changes action.
- Save only changed sections in order; retain input and retry only failed sections after partial failure.
- Align Information headings/spacing, remove redundant dividers and the tool-recheck button, and inspect tool status automatically on entry.
- Reduce repeated page descriptions, show authentication guidance once and make filename-variable help expandable.
- Remove custom favicon upload and use the default Phrolova icon.

## Statistics

- Show disk total/used/free capacity, utilization, space status, drive and filesystem.
- Show separate copyable live/video paths, including existing split-path configurations.
- Do not display unavailable disk measurements as 0%; improve quantities and narrow layouts.

## Logs and export

- Show file counts, total size, recent activity and current/backup retention summaries.
- Combine severity filtering and search with loaded error/warning/general counts.
- Reduce icons/excess whitespace and improve panel heights, live updates, auto-scroll and file switching.
- Export the selected file in full, preserving original text regardless of search or the visible line limit.

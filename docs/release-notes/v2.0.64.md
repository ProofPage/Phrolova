# Version 2.0.64

## 설정과 메뉴 정리
- 동영상 다운로드·녹화 파일 처리·라이브 녹화 설정을 하단 오른쪽의 **변경사항 저장** 한 버튼으로 저장합니다.
- 변경한 영역만 순서대로 저장하며, 일부 저장에 실패해도 입력을 유지하고 실패한 영역만 다시 저장할 수 있습니다.
- 정보 탭의 제목·정렬·간격을 통일하고 **도구 다시 검사** 버튼과 중복 구분선·불필요한 여백을 제거했습니다. 도구 상태는 정보 탭을 열 때 자동으로 확인합니다.
- 라이브·동영상·통계·로그·설정의 반복 설명을 정리하고 인증 공통 안내는 한 번만 표시합니다. 긴 파일명 변수 설명은 펼쳐볼 수 있습니다.
- 탭 아이콘 업로드 설정을 제거하고 기본 Phrolova 아이콘을 사용합니다.

## 통계 정보 개선
- 디스크 전체 용량·사용 중·여유 공간·사용률, 공간 상태와 드라이브·파일 시스템을 함께 표시합니다.
- 라이브·동영상 저장 경로를 구분하고 각 경로를 복사할 수 있습니다. 구버전에서 나눈 다운로드 경로도 실제 설정대로 표시합니다.
- 디스크 수치를 확인할 수 없을 때 0%로 표시하지 않으며, 수량 문구와 작은 창의 배치를 개선했습니다.

## 로그 화면과 내보내기
- 파일 수·전체 용량·최근 기록, 현재 로그·백업의 보관 현황을 표시합니다.
- 불러온 로그의 오류·경고·일반 개수를 확인하고 분류와 검색을 함께 사용할 수 있습니다.
- 아이콘과 과도한 빈 공간을 정리하고 좌우 패널 높이, 실시간 갱신·자동 스크롤 및 파일 전환을 개선했습니다.
- **로그 내보내기**는 선택한 파일 전체를 원문 그대로 저장합니다. 검색 조건과 화면의 줄 수 제한은 내보내기에 영향을 주지 않습니다.

## 검증과 호환성
- 백엔드 전체 검사: **902 passed, 1 skipped, 4 subtests passed**. 별도 활성화가 필요한 3 GiB 초과 TS 검사만 제외했습니다.
- 한국어·영어·일본어·스페인어·독일어·중국어 간체·중국어 번체·러시아어에 각각 839개 번역을 제공합니다.
- TypeScript·제품 빌드 및 번역 키·변수·복수형·날짜·숫자 검사, 8개 언어의 전체 페이지와 설정 하위 탭에서 320/390/1440px 배치·언어 전환/복원 검사를 통과했습니다.
- 통합 설정의 저장·검증·부분 실패/복구·중복 요청 방지, 로그 검색·분류·갱신·파일 전환·원문 내보내기를 모의 API에서 검증했습니다.
- 기존 사용자 데이터와 저장 경로, Streamlink 녹화·TS/fMP4 원본·FFmpeg 후처리·MKV 기본 저장과 MP4 선택, 기존 다운로드 기능을 유지합니다.

# Phrolova v2.0.99

## Auto-Unblock on Credential Registration
- Fixed an issue where channels added before logging in failed with `empty_stream` / auth errors and stayed permanently blocked in `retry_blocked` state even after the user logged in or uploaded credentials.
- Adding or updating platform credentials (RPLAY, YouTube, CIME, Chzzk, etc.) now immediately notifies Conductor to unblock affected channels and trigger an instant scan to begin automatic recording.

## Validation
- Unit tests verifying channel unblocking and instant scan triggers passed.
- 63 core platform and renewal tests passed.
- Release metadata tests passed.

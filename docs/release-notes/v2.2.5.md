# Phrolova v2.2.5

## Scheduled recording

- Add per-channel weekly monitoring windows, including overnight schedules and early checks.
- Keep ongoing recordings running when the monitoring window ends.
- Preserve always-on monitoring as the default and allow manual recording outside scheduled windows.

## Recording fixes

- Use the actual restart time for subsequent recording sessions instead of reusing the original broadcast timestamp.
- Migrate legacy recording filename templates while preserving existing recordings.
- Refresh RPLAY playback grants during reconnection and preserve signed URL parameters.
- Give YouTube source resolution more time than its internal extraction timeout.
- Preserve receiver cleanup and same-file recovery when a stream connection fails.

## Startup updates

- Automatically download and apply available updates on startup in supported Windows executable and managed script installations.
- Verify Windows release checksums before launching the replacement helper.
- Gracefully shut down the Windows app for replacement and restart it afterward.
- Preserve settings, application data, logs, and recordings.
- Publish both versioned and stable Windows executable names with SHA-256 checksums.

# Version 2.0.66

## Startup and logging

- Remove startup separators and align tool names, versions and executable paths, wrapping long paths to terminal width.
- Label Uvicorn lifecycle messages as SERVER and separate platform/task logs for CHZZK, YouTube, SOOP, CIME, external videos and legacy X Spaces categories.
- Include channel, session, error code and retry details in recording failures; include processing stage, exit code and source-retention status in finalization failures.
- Hide repetitive successful HTTP requests by default, retaining debug visibility; write 4xx/5xx requests to logs as warnings/errors.
- Keep exception stacks in the web error filter and classify older lowercase levels correctly.
- Distinguish update-check 404s, rate limits, network errors and timeouts without reporting a failed check as an empty release list or an up-to-date result.

## Mobile and icons

- Use 16px live/download URL inputs and sorting selectors.
- Keep platform choices at 44px touch targets on tablets and landscape screens; arrange narrow log actions in two columns.
- Apply a circular transparent icon to the executable, tray and browser, with ten ICO sizes from 16–256px.
- Replace missing-license-file build references with bundled THIRD_PARTY_NOTICES.

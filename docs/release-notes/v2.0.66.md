# Version 2.0.66

## 시작 화면과 로그
- 시작 전 점검의 구분선을 없애고 항목·버전·실행 경로를 정렬했습니다. 긴 경로는 터미널 폭에 맞춰 줄바꿈합니다.
- 서버 시작 로그의 `uvicorn.error` 표시를 `SERVER`로 정리하고, 플랫폼 및 작업별 로그를 구분했습니다. 치지직·유튜브·숲·씨미·외부 동영상·X Spaces 분류를 보완했습니다.
- 녹화 실패에는 채널·세션·오류 코드·재시도 정보를, 파일 변환 실패에는 처리 단계·종료 코드·원본 보관 여부를 기록합니다.
- 반복되는 정상 HTTP 조회는 기본 출력에서 제외하고 4xx·5xx 요청은 경고·오류로 파일에도 기록합니다. 디버그 모드에서는 정상 요청도 확인할 수 있습니다.
- 웹 오류 필터에서 예외 스택과 상세 설명을 함께 표시합니다. 소문자로 기록된 과거 로그도 올바르게 분류합니다.
- 업데이트 조회의 404·요청 제한·연결 오류·시간 초과를 구분합니다. 실패를 릴리즈 없음이나 최신 버전 확인으로 잘못 알리지 않습니다.

## 모바일
- 라이브 채널·다운로드 URL 입력창과 작업 정렬 선택창의 글자를 16px로 맞췄습니다.
- 태블릿과 가로 화면에서도 플랫폼 선택 항목의 터치 영역을 44px로 유지합니다.
- 좁은 로그 화면의 내보내기·실시간 갱신·자동 스크롤·새로고침 버튼을 2열로 정렬했습니다.

## Windows 아이콘
- 새 원형 투명 이미지를 실행 파일·트레이·브라우저 아이콘에 적용했습니다. ICO는 16~256px의 10개 크기를 포함합니다.
- 삭제된 라이선스 파일을 참조하던 빌드 설정을 수정하고 외부 코드 고지를 `THIRD_PARTY_NOTICES`에 보관합니다.

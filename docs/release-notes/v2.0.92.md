# Phrolova v2.0.92

## YouTube live metadata & preview fixes
- **Viewer count & profile image parsing**: Update YouTube live HTML scrapers to parse modern `videoViewCountRenderer` runs arrays, channel avatars (`yt3.ggpht.com`), and owner channel names.
- **Cookie propagation**: Forward registered YouTube cookies to live monitoring HTTP checks and preview media proxy requests.
- **Instant preview for recording streams**: If a YouTube live is already actively recording, reuse its established stream URL directly for dashboard preview playback, avoiding redundant yt-dlp queries and bot verification walls.
- **URL normalization**: Correctly resolve YouTube channel, handle, and video watch URLs without producing invalid `@https://...` handles.

- Release metadata checks passed.

# Phrolova v2.0.80-preview.24

Preview release fixing `get_settings` import in SOOP engine and ensuring 1080p preset options populate in channel settings.

### Key Changes
- **Fix `get_settings` NameError in SOOP Engine**:
  - Added missing `from app.core.config import get_settings` import in `backend/app/engine/soop.py`.
  - Resolves `name 'get_settings' is not defined` when loading live channel qualities, allowing 1080p, 720p, 540p, and 360p presets to populate cleanly in the channel addition dialog.

- **Inherited from Earlier Previews**:
  - SOOP domestic 540p cap and P2P grid bypass via global unthrottled CDN mapping.
  - Prioritized CIME 4K UHD stream selection and exposed 4K in quality presets.
  - CIME VOD CloudFront signed cookies auto-acquisition.
  - Switched YouTube live and video processing to standalone `yt-dlp` executable.
  - Silenced Windows asyncio proactor connection reset error logs.
  - HearHeart uploader and duration metadata population.
  - Fixed `USER_AGENT` import origin in `hearheart.py`.
  - HearHeart VOD/playlist download capabilities exposed in UI selector.
  - Native HearHeart (`hearheart.com`) VOD and playlist downloads via yt-dlp `HearHeartIE`.
  - HearHeart cookie registration support in Settings -> Authentication.
  - Fixed TikTok live preview video player startup stalled by non-zero FLV stream PTS.
  - Dedicated video player for TikTok live previews without static frame fallbacks.
  - Encapsulated pure ES module packaging for `mpegts.js`.
  - Prioritized browser-compatible H.264 video streams for TikTok live previews.
  - Fixed SQLite `recording_jobs.source_path` unique constraint collision on recording restart.
  - Bilibili preview resolution and CDN failover optimization.
  - Eliminated CHZZK "재연결 중" / "녹화 중" false-alarm status flickering.
  - Remux duration inspection tolerance for live stream TS discontinuities.
  - Instant guest CHZZK preview resolution without initial 502 errors.
  - Automatic RPLAY session renewal via IndexedDB `refreshToken`.

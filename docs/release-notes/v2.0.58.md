# Version 2.0.58

## 미디어 도구 설정 화면 개선
- FFmpeg와 FFprobe가 모두 정상일 때 설치 안내를 숨깁니다. WinGet 또는 PATH로 설치된 도구도 정상 감지 상태 그대로 표시합니다.
- 도구 이름·정상 상태·실행 경로를 분리하여 읽기 쉽게 정렬했습니다. 경로는 보조 색상과 고정폭 글꼴을 사용합니다.
- 긴 Windows 경로가 모바일 화면 밖으로 넘치지 않도록 줄바꿈합니다.
- 도구가 없거나 실행에 실패한 경우에만 설치 및 경로 설정 안내를 펼쳐 볼 수 있습니다.
- 상태 조회 요청이 실패하면 설치 누락으로 오인하지 않고 조회 오류를 표시합니다. 도구 다시 검사와 정상 복구 동작을 유지합니다.

## 검증
- TypeScript 검사·프런트엔드 빌드 통과.
- 360px·1280px 브라우저에서 정상·누락·요청 실패·재검사 복구 및 가로 넘침 검사 통과.
- 기존 도구 탐색·설치·녹화·후처리 API와 사용자 설정은 유지합니다.

# Version 2.0.23

## Live recording

- Fixed live recording startup with Streamlink by removing an unsupported HLS-only option from FFmpeg's pipe input.
- Streamlink continues to receive HLS while FFmpeg records the media stream.

## VOD downloads and task cleanup

- Keep VOD downloads on yt-dlp with FFmpeg available for merging and post-processing.
- Allow queued, completed, and failed tasks to be cleared; downloading and paused tasks are preserved.
- Persist cleanup and retry deletion of cancelled partial files when Windows releases file locks.

Download the Windows x64 executable and replace the existing application executable. Settings and saved data are preserved.

# 다국어 구현 및 검증 기록

검토 기준: 2026-10-13 현재 작업 파일과 `312e08d`(v2.0.62)의 Git 변경 내역. 이전 설명에서 기능을 재구현하지 않고 현재 실행 경로를 조사했다.

## 현재 기능과 번역 범위

React 19·TypeScript·Vite·Tailwind 기반 UI와 FastAPI 백엔드다. 기존 LanguageContext를 재사용했으며 새 제품 의존성은 추가하지 않았다.

실제 페이지는 라이브, 동영상, 통계, 시스템 로그, 설정이다. 별도 미디어 허브 페이지는 현재 없으므로 새로 만들지 않았다. 플랫폼은 내부 ID `chzzk`, `youtube`, `soop`, `cime`을 유지한다. 동영상의 기존 외부 URL 입력도 유지한다.

번역 범위:

- 라이브 카드·목록·필터·태그·정렬, 채널 등록/삭제, 자동 녹화, 녹화 설정/시작/중지, 감시/녹화 상태, 시청자 수, 미리보기와 파일 처리/검사/재시도 안내.
- 동영상 URL 입력·등록·준비 목록·다운로드 카드, 진행률/속도/남은 시간, 일시정지/재개/취소/재시도, 파일 검사·파일/폴더 열기.
- 통계 수치·날짜·시간·기간·저장 공간, 시스템 로그 목록/검색/새로고침/정리. 기술 로그 본문은 원문을 보존한다.
- 설정의 다운로드·인증·알림·외관·정보 탭 전체, 기본 설정 마법사와 폴더 선택, 화질/파일 형식·저장 경로·CDN 설정.
- 사이드바·상단 메뉴·빠른 이동·알림 센터, 공용 버튼/필드/상태/빈 화면/로딩/확인 팝업, 접근성 이름.

정보 탭에 서버 주소를 다시 추가하지 않았다. Streamlink·FFmpeg·FFprobe 상태와 설치 경로, 도구 재검사 배치를 유지한다.

각 JSON은 독립적인 번역이다. 중국어 번체에는 대만 용어인 影片·下載·資料夾·檔案·匯入 등을 사용했다. 번체를 간체 문자 변환으로 만들지 않았다. CHZZK·YouTube·SOOP·CIME 브랜드, Streamlink·FFmpeg·FFprobe·TS·MKV·MP4 식별자, 경로/URL/사용자 이름과 영상 제목은 유지한다. `같이보기`는 실제 태그 조건 값이므로 예시와 설명에서도 원문을 유지한다.

네임스페이스는 `common`, `live`, `download`, `settings`, `setup`, `stats`, `logs`, `platform`, `errors`다. 실제 알림 열거형에 없는 과거 알림 키 6개와 문장 연결에 사용하던 미사용 조각 키 11개를 정리했다. X Spaces/채팅 기록/라이브 채팅 저장을 위한 키나 UI를 만들지 않았다. 과거 테스트 자료와 기록 문서는 이번 번역 리소스로 가져오지 않았다.

## 언어 전환과 호환성

`src/contexts/LanguageContext.tsx`가 앱 전체 언어 상태를 제공하고, Context 객체는 번역 모듈 갱신과 분리한 `LanguageState.ts`에서 공유한다. `src/i18n/index.ts`가 번역·변수·Intl 포맷·복수형·폴백을 담당한다.

- 기본값은 `ko-KR`다. 기존 저장 값 `ko/en/ja`는 새 로케일로 읽는다. 잘못된 값은 한국어로 폴백한다.
- 기존 외관 탭에 8개 선택지를 둔다. 선택 즉시 전체 UI와 `html.lang`이 바뀐다.
- 기존 localStorage 키 `phrolova-language`에 저장하고 새로고침/다음 실행에서 복원한다. 다른 탭의 저장 변경도 반영한다. 저장소 접근이 막혀도 현재 세션 전환은 가능하다.
- 파일 저장 경로·백엔드 설정·쿠키·채널/다운로드 데이터는 언어 설정과 별도로 보존한다. 설정 파일을 초기화하지 않는다.
- 새 문구는 의미 키와 `{name}` 같은 변수로 작성한다. 숫자는 Intl.NumberFormat, 날짜는 Intl.DateTimeFormat, 수량은 Intl.PluralRules를 사용한다. 러시아어 one/few/many와 21 같은 수량을 검증했다.
- 알림은 가능하면 키와 원래 변수값을 저장한다. 화면과 알림 내역을 다시 렌더링할 때 현재 언어로 표시한다. 기존 문자열 메시지를 위한 원문 별칭과 동적 문구 대응도 유지한다.
- 누락된 의미 키는 한 번 경고하고 현지화된 대체 문구를 표시한다. 리소스 검사에서 누락·빈 값·중복·변수 불일치를 검출한다.

예:

```tsx
const { t } = useLanguage();
t('live.previewLabel', { name: channel.channel_name });
toast.success('common.tagDeleted', { tag: tagName });
```

`aliases.json`은 기존 API 문구와 상태값의 표시 호환용이다. 새로운 UI의 키를 한국어 문장으로 만들지 않는다. 내부 상태/플랫폼 ID, 파일명 템플릿 변수, API 페이로드는 번역하지 않는다.

## 오류 표시와 엔진 보호

HTTP 오류에 `message_key`를 추가하고 기존 `detail`, HTTP 상태 코드와 헤더를 유지한다. 요청 검증 오류도 기존 FastAPI `detail` 배열을 유지하며 `errors.invalidInput`을 추가한다. 프론트엔드는 알려진 문구/키를 번역하고, 알 수 없는 서버 오류는 현지화된 오류 안내로 표시한다. 파일 검사/녹화/미리보기 동적 안내도 같은 방식으로 처리한다. 오류 상세 펼침과 처리 로그의 기술 원문은 보존한다.

녹화·다운로드 엔진의 종료 조건·취소·버퍼·품질·파일 경로·포맷 처리는 변경하지 않았다. 현재 Streamlink 원본 감지(TS/fMP4 포함), TS 정규화와 FFmpeg 후처리, MKV 기본 완료 형식과 선택 가능한 `MP4 - MPEG-4`를 유지한다. 시스템 정보의 Streamlink 검사는 녹화에서 쓰는 Python 패키지의 실제 설치 경로와 정상 로딩을 확인한다.

## UI와 발견한 문제

- 언어 훅을 Provider 밖에서 호출해 실시간 미리보기가 빈 화면이 된 문제를 수정했다. 번역 모듈 자동 갱신 시 Provider/소비자 Context가 달라지는 문제도 수정하고, 실제 HMR 갱신/복원 검사를 통과했다.
- 플랫폼 이름에 번역 키가 그대로 표시될 수 있던 곳과 확인 입력값의 표시/비교 언어를 맞췄다.
- 파일 검사 경고·쿠키 상태·서버 응답 알림의 표시를 현지화했다.
- 길어진 녹화 버튼/상태/통계 이름과 다운로드 검사 배지가 카드 밖으로 밀리지 않도록 줄바꿈과 배치를 보완했다.
- 일본어·중국어 줄바꿈 규칙을 적용했다. 기존 미리보기·카드·버튼 위치와 정보 탭 구성은 유지한다.

## 검증

```bash
cd frontend
npm run i18n:check
npm run i18n:test
npx tsc --noEmit -p tsconfig.json
npm run build
```

저장소 루트에서 실행하는 브라우저 검사:

```bash
PHROLOVA_TEST_URL=http://127.0.0.1:3001 python frontend/tests/i18n_regression.py
```

결과:

- 정적 검사: 8개 언어 각 807개 키. 키 집합 차이·누락·빈 값·중복·변수 불일치·한국어 JSX/접근성 하드코딩 0건.
- 코어 검사: 로케일 이전 값/잘못된 값, 날짜·숫자·바이트, 변수 치환, 러시아어 복수형, 기존 메시지 언어 전환, 누락 키 감지와 경로/URL/포맷 보존 통과.
- 브라우저 검사: 8개 언어 × 5개 페이지, 설정 하위 탭과 알림 종류/쿠키 상태, 320/390/1440px 가로 넘침·버튼 잘림, 즉시 전환/새로고침 복원, 기본 설정·녹화·업데이트 팝업, 기존 알림의 즉시 언어 갱신, 자동 녹화/시작/중지 요청, 삭제 기능 비노출 통과.
- 기존 회귀 검사: 기본 설정 마법사, 설정 저장 범위/실패 재시도, 정보 탭 도구 상태, 녹화 카드와 다운로드 동작 통과.
- `i18n_hmr.py`: 번역 리소스를 2회 갱신/복원하여 개발 미리보기의 빈 화면·Context 오류가 재발하지 않음을 확인했다. 검사 후 리소스 원본을 복원한다.
- TypeScript와 제품 빌드 통과.
- 백엔드 전체: **886 passed, 1 skipped, 4 subtests passed**. 건너뛴 항목은 별도 활성화가 필요한 3 GiB 초과 TS 생성 검사다. API 오류 구조, Streamlink 도구 검사, 녹화 시작/종료·TS/fMP4·MKV/MP4 처리·다운로드 관련 회귀 검사 포함.

브라우저 동작 검사는 격리된 컨텍스트와 모의 API를 사용하며 사용자의 설정/채널을 변경하지 않는다. 실제 외부 방송에 로그인해서 장시간 녹화/다운로드하는 검사는 이번에 실행하지 않았다. 빌드에는 JS 청크 크기 경고가 남아 있으며 빌드 실패는 아니다. 배포 기록은 `docs/release-notes/v2.0.63.md`에서 확인한다.

# 숲·씨미 라이브 플레이어 수정 (2026-10-12)

## 원인과 수정

- `LivePreview.tsx`가 숲·씨미에서 `LiveFramePreview`를 선택했습니다. 수 초마다 JPEG를 교체하므로 재생·음량·전체화면 조작이 없고 움직임이 끊겼습니다. 모든 영상 플랫폼을 기존 HLS 플레이어로 연결했습니다. 프레임 API는 기존 계약을 보존합니다.
- 서버 프록시에 숲·씨미 Origin/Referer와 도메인별 CookieJar를 적용했습니다. 인증서 검증, CDN 허용 범위, 서명 URL 숨김은 유지합니다.
- 실제 앱처럼 Streamlink와 yt-dlp를 함께 import하면 yt-dlp의 정규식 래퍼가 Streamlink 래퍼의 동적 메서드를 찾지 못했습니다 (`Urllib3UtilUrlPercentReOverride ... no attribute sub`). 정상 속성 조회로 연결하고 두 import 순서 및 서명 URL의 소문자 퍼센트 인코딩 보존을 새 Python 프로세스에서 검사합니다.
- HLS 화질은 네트워크에 맞게 자동 조정하고 선호 화질은 상한으로 사용합니다. 재연결 때 사용자가 바꾼 음량·음소거 설정을 초기화하지 않습니다. 연결 오류·429·5xx는 5초 후 한 번 자동 재시도합니다.
- 좁은 채널 카드에서는 미리보기를 상세 정보 위에 두어 플랫폼별 메타데이터 수에 따라 영상 시작 위치가 달라지는 문제를 없앴습니다. 넓은 목록은 정보와 영상을 나란히 유지합니다.
